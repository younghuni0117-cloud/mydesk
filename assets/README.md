# 생성형 지형 그림

`terrain-atlas-v9.webp`는 이 홈페이지용으로 새로 생성한 선명한 만화풍 풍경입니다. 2열×4행의 넓은 패널 8개이며 왼쪽부터 행 순서대로 초원·언덕·돌길·계단·공사장·바위 언덕·빙판·동굴입니다. 외부 사진이나 다른 게임의 이미지를 복사하지 않았습니다.

강한 잉크 외곽선·셀 음영·뚜렷한 색을 사용하고 안개·흰색 오버레이를 사용하지 않습니다. 원본 PNG를 크기 변경 없이 WebP quality 94로 인코딩했습니다. `terrain-atlas.webp`는 이전 버전 배경 기록입니다. 실제 접촉면·초목·암석·동굴 천장은 물리 지형 데이터에 맞춰 별도로 그립니다.
