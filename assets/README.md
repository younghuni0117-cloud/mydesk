# 지형 그림

`terrain-atlas.webp`는 이 홈페이지를 위해 이미지 생성 도구로 제작한 만화풍 풍경입니다. 외부 사진이나 다른 게임의 이미지를 복사하지 않았습니다. 짙은 선과 수채화 느낌, 크림·청록·황토색을 사용해 로봇 외형과 맞췄습니다.

왼쪽부터 초원·언덕·돌길·계단·공사장·바위 언덕·빙판의 일곱 열입니다. 원본 PNG를 크기 변경 없이 WebP(quality 90)로 인코딩해 약 608KB로 줄였습니다. 배경은 원근 풍경이며 실제 충돌면은 `robot-scenery.mjs`에서 물리 지형 자료에 맞춰 별도로 그립니다.
