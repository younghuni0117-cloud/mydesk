# 생성형 지형 그림

`terrain-atlas-v9.webp`는 이 홈페이지용으로 새로 생성한 선명한 만화풍 풍경입니다. 2열×4행의 넓은 패널 8개이며 왼쪽부터 행 순서대로 초원·언덕·돌길·계단·공사장·바위 언덕·빙판·동굴입니다. 외부 사진이나 다른 게임의 이미지를 복사하지 않았습니다.

원본 PNG를 크기 변경 없이 WebP quality 94로 인코딩했습니다. 현재 야외 7개 지형은 이전의 부드러운 색감인 `terrain-atlas.webp`를 사용합니다. 동굴은 `terrain-atlas-v9.webp`의 마지막 패널을 사용하며, 두 배경 모두 밝은 바탕에 불투명도 64%로 그려 색의 강도를 낮춥니다. 실제 접촉면·초목·암석·동굴 천장은 물리 지형 데이터에 맞춰 별도로 그립니다.

사막은 아틀라스 대신 `robot-scenery.mjs`의 부드러운 황금색 모래 언덕과 태양으로 직접 그립니다. 지형 목록 재정렬과 무관하게 기존 아틀라스 패널 위치는 고정합니다. 등산객은 `robot-skin.mjs`에서 각 신체 부위의 의복·얼굴을 그린 원본 캐릭터이며 다른 게임의 이미지를 사용하지 않습니다.

김도윤·임선아 팬 스킨은 `robot-skin.mjs`에서 직접 그립니다. 캐릭터 외형은 상C 작가의 [공식 작품](https://comic.naver.com/webtoon/list?titleId=836848)과 [WEBTOONFRIENDS 공식 단행본 홍보](https://mkt.shopping.naver.com/link/68fb383bdb0ddd370ee28351?nt_detail=44thperiod&nt_keyword=book1-2&nt_medium=sns.ig&nt_source=linktree)를 참고했습니다. 홍보 이미지 원본은 배포하지 않습니다.
