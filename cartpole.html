카트폴 도움말

난이도와 학습 시도 횟수(1~10,000회)를 고르고 ‘학습 시작’을 누르세요. 게임을 시작해서 실패하거나 20초에 도달할 때까지가 1회입니다. 1,000회를 입력하면 학습 시도를 정확히 1,000번 수행합니다. 그래프를 위한 별도 성능 평가 8회는 학습 시도 수에 포함하지 않습니다. 중지 시 완료한 시도와 진행 중인 전략 평가를 저장해 다음 요청에서 이어갑니다. 학습이 끝나면 ‘학습 모델 실행’으로 해당 난이도에서 평균 누적 보상이 가장 높았던 모델을 실행합니다. 학습과 실행은 분리되어 있고, 실행 중에는 모델 가중치가 바뀌지 않습니다. ‘직접 도전’에서는 ← → 방향키나 터치 버튼으로 조작할 수 있습니다.

난이도 안내

쉬움은 긴 막대와 ±20° 허용 범위, 기본은 ±12°, 어려움은 짧은 막대와 ±10°입니다. 2단 관절은 두 막대가 직렬로 연결되고 각 관절이 독립적으로 움직입니다. 두 막대 중 하나라도 수직 기준 ±20°를 넘으면 종료합니다. 모든 난이도는 카트 ±2.4m 이탈 시 종료하며, 목표는 20초입니다.

상벌점 규칙과 종료 모션

유효한 매 스텝에 +1점을 주고, 기울기 감점 −0.2×평균(막대 각도/허용 각도)², 위치 감점 −0.05×(카트 위치/2.4)², 제어 감점 −0.01×입력 힘²을 적용합니다. 실패 시 −100점, 20초 성공 시 +100점입니다. 실패 시 학습 기록과 점수를 확정한 뒤, 제어 입력 없이 바닥에 닿아 튕기고 가라앉는 모션을 이어갑니다. 종료 모션에는 보상이 추가되지 않습니다.

그래프와 저장 모델

회색 점선은 각 평가 시점 후보의 평균 누적 보상, 파란 실선은 지금까지 가장 높은 평균 보상을 얻은 보존 모델입니다. 세로축 단위는 점수이며 음수 감점도 표시합니다. 매번 같은 8개 시작 조건을 사용하며, 20초 성공률도 이 8회 평가 기준입니다. 실제 실행은 새로운 시작 조건이므로 기록이 달라질 수 있습니다. 난이도마다 모델·그래프·내 최고 기록을 따로 저장합니다.

01 / OBSERVE

상태를 관찰해요

카트의 위치·속도와 각 막대의 각도·각속도를 관찰합니다. 1단은 4개, 2단은 6개 상태를 사용합니다.

02 / REWARD

오래 버틸수록 좋아요

유효한 0.02초마다 +1점에서 자세·위치·제어 감점을 뺍니다. 실패는 −100점, 20초 목표 달성은 +100점 보너스입니다.

03 / POLICY SEARCH

좋은 전략을 이어가요

정책 탐색(CEM)으로 1단은 25개, 2단은 49개 전략을 각각 3회 시도하며 모델을 개선합니다. 입력한 횟수에서 정확히 멈추고, 아직 끝나지 않은 전략 평가는 다음 학습으로 이어갑니다. 상위 전략으로 다음 후보를 만들고, 별도 고정 조건에서 평가합니다.

미로와 카트폴은 각각 독립된 실험입니다. 카트폴의 AI 학습과 내 최고 기록은 이 브라우저에 저장됩니다.
