로봇 안내·저장

캐릭터 선택

탐험가·깡통 로봇·스타워즈형·등산객·김도윤·임선아 중 캐릭터를 선택할 수 있습니다. 외형만 바뀌고 관절·물리 조건·학습 모델은 같은 로봇을 유지합니다. 선택한 외형은 이 기기에 저장됩니다.

김도윤·임선아는 상C 작가의 《44교시 생존수업》 캐릭터를 단순화해 직접 그린 팬 스킨입니다.

정해진 동작 없이 처음부터 학습

기본 자세 유지·걷는 주기·발 들기·팔로 밀어 일어서기·무릎 각도 계산 같은 기본 동작은 없습니다. 새 통합 모델의 초기 관절 토크는 0입니다. PPO를 처음 선택할 때도 출력층은 0으로 유지하고, 숨은 특징만 무작위로 초기화합니다. 학습 중 무작위 행동은 탐색이며 미리 정한 동작이 아닙니다. 학습 중에는 보상으로 신경망 가중치를 탐색하며, 하나의 공통 정책을 다섯 운동 과제에서 사용합니다. 초기화 직후에는 중력·충돌·관절의 수동 탄성 때문에 움직이거나 쓰러질 수 있지만 자동으로 일어서거나 걷도록 제어하지 않습니다.

신경망은 센서·목표 입력 47개 → 은닉 12개 → 관절 힘 16개이며 학습 가중치는 784개입니다. 물리 상태에 반응하는 정책을 개선 CEM 또는 PPO로 학습하며, 시범 동작이나 미리 훈련한 가중치는 쓰지 않습니다. 목표 운동을 성공하기까지 많은 시도가 필요할 수 있으며 성공을 보장하지 않습니다.

명령·목표 설정

상세 옵션 위의 명령·목표 설정은 기본적으로 접혀 있습니다. 제자리 유지·계속 이동·목표 위치로 이동, 앞뒤 방향·속도·낮은 자세를 선택합니다. 통합 모델 실행 중 변경하면 몸·속도·관찰시간을 초기화하지 않고 목표만 바꿉니다. 지형에서 목표 선택을 켠 다음 화면을 누르면 그 위치로 지정합니다. 선택 중 다시 버튼을 누르면 취소합니다. 화면의 정지는 현재 위치에 머물라는 목표이며 물리 동작을 강제로 멈추지 않습니다. 낮은 자세도 관절 각도를 지정하는 동작이 아닙니다. 충분히 학습되지 않으면 명령을 수행하지 못할 수 있습니다.

각 12개 후보 묶음은 같은 목표 조건을 경험합니다. 기본 운동, 뒤로 이동 후 정지·왕복·위치 도착, 낮은 자세와 사용자가 선택한 목표를 순환해 학습합니다. 실행 중 목표가 바뀌거나 넘어져도 관절 동작은 같은 신경망이 정하며 자동 일어서기 동작은 없습니다. 통합 모델 채택에는 기존 다섯 운동 능력의 검증과 별도의 고정된 명령 시험 보상을 함께 사용합니다. 표·그래프는 기존 운동별 네 조건 검증 값이며 명령 시험 점수는 합산하지 않습니다.

학습 방식·난이도

상세 옵션에서 개선 CEM과 PPO를 선택합니다. CEM은 한 묶음의 시작 자세·밀기·목표를 동일하게 두고, 반대 방향의 가중치 변화를 쌍으로 비교합니다. PPO는 각 행동과 이후 보상으로 정책과 가치 함수를 갱신합니다. 두 방식 모두 하나의 통합 모델을 사용하고 학습 횟수는 실제 시도로 셉니다. PPO가 항상 더 좋은 결과를 보장하는 것은 아닙니다.

단계별 학습을 켜면 기본 운동을 먼저 연습하고, 해당 운동이나 균형의 검증 통과율이 50% 이상일 때 명령 변경 조건을 섞습니다. 설정한 밀기 최소·최대 범위 안에서 약한 쪽부터 시작해, 검증 성능이 좋아질수록 상한과 초기 흔들림을 높입니다. 검증의 밀기 세기는 고정되어 있습니다. 미숙한 능력의 점수는 탐색 중 변할 수 있지만, 이전에 통과한 검증 조건을 잃은 후보는 통합 모델로 채택하지 않습니다.

상점·벌점 기준

아래 값은 실제 보상 계산과 같은 설정에서 표시합니다. 초당 점수는 물리 시간에 비례해 누적합니다. 표의 평균 보상은 고정된 네 조건에서 받은 누적 점수의 평균입니다. 이전에 통과한 검증 조건이나 숙련 능력의 보존 기준을 벗어난 후보는 남은 검증을 생략합니다. 아직 평가하지 않은 능력의 후보 점선은 비워 두며, 통합 모델 채택 전에는 모든 검증을 마칩니다.

모든 운동 능력의 공통 상점·벌점

밀려도 버티는 학습

상세 옵션에서 학습 전에 자동 밀기를 켜면 각 시도에서 무작위 시점·방향으로 한 번만 밉니다. 상세 옵션에서 세기의 최솟값·최댓값을 0.1~30 N·s 범위로 정합니다. 처음 값은 1~6 N·s입니다. 최근 모델 관찰에서도 해당 시도의 밀기를 재현합니다. 통합 모델 실행은 자동으로 밀지 않으며 마우스로 직접 시험할 수 있습니다. 직접 밀기는 학습에 포함되지 않습니다. 밀림에 대한 적응을 연습하지만 모든 외력을 견딘다는 보장은 아닙니다. 표의 검증은 설정과 별개로 동일한 정지·외력 조건에서 평가합니다.

실제 물리와 관찰

보조 지지력 없이 17개 강체·16개 회전 관절을 계산합니다. 신경망이 관절에 가할 토크를 직접 정합니다. 물리적인 관절 각도 제한·마찰·질량·수동 허리 탄성은 유지하지만 자동 자세 교정이나 기본 운동 동작은 없습니다. 관절 한계와 실제 모터의 힘·속도 한계는 물리 조건으로 적용합니다. 1회는 8~12초 가상 시간의 시도이며 검증·재생은 별도입니다. 그래프는 선택한 운동 과제의 실제 평균 보상이며 표의 해당 행과 같은 값입니다. 가로축은 선택한 운동 능력의 0회부터 현재 학습 횟수까지이며, 다른 운동 능력의 횟수는 합산하지 않습니다. 이전 버전에 과제별 횟수 기록이 없으면, 한 과제만 학습한 경우에만 과거 횟수를 복원합니다. 여러 과제가 섞인 구간은 새 평가부터 표시합니다. 학습 중에는 최근 모델이 실제 시도에서 만든 움직임을 부드럽게 재생하여 중복 물리 계산을 줄입니다. 직접 밀기나 통합 모델 실행은 실시간 물리로 시험합니다. 중간 관찰은 최근 모델을 다시 실행하고, 통합 모델 실행은 검증을 거쳐 저장한 가중치로 시험합니다. 상세 옵션에서 관찰시간을 1~3600초로 정하고 갱신 간격도 바꿀 수 있습니다. 관찰시간은 학습·검증 시도의 길이에 영향을 주지 않습니다.

마우스 왼쪽 버튼으로 로봇을 잡아 드래그하면 놓는 방향과 거리에 따라 밀립니다. 오른쪽 버튼으로 드래그하면 화면을 이동하고 휠로 확대·축소합니다. 터치는 한 손가락으로 로봇을 밀고 두 손가락으로 이동·확대합니다. 기본은 지형 고정이며 보기 선택에서 로봇 중심으로 바꿀 수 있습니다. ‘맞춤’은 선택한 보기의 초기 시야로 돌아갑니다. 학습은 현재 기기의 CPU에서 실행됩니다. 코어가 4개 이상으로 보고되는 환경에서는 최대 두 후보를 동시에 계산합니다. 결과는 원래 시도 순서대로 반영하며, 병렬 실행을 지원하지 않거나 실패하면 순차 계산으로 이어갑니다. 검증 조건과 물리 계산 간격은 그대로 유지합니다. 관찰은 화면 주사율에 맞춰 보간하며 모바일에서는 렌더링 해상도를 조절합니다. 창이 숨겨지면 학습 중지를 요청합니다.

업데이트와 그래프

모델·학습 횟수·탐색 상태와 이전 그래프를 유지합니다. 이번 보상 기준 변경 전 원본은 따로 보관하고 내려받을 수 있습니다. 새 점수와 옛 점수는 단위가 달라 상세 옵션의 보상 기록에서 구분합니다. 그래프 범위는 전체 또는 최근 N회이며 직접 입력할 수 있습니다. 표시 범위를 바꿔도 데이터를 삭제하지 않습니다.

이 기기에 저장

학습 결과는 현재 기기의 이 브라우저에 자동으로 저장됩니다. 같은 브라우저로 다시 열면 이어 사용할 수 있습니다. 고정된 저장 키를 쓰고 IndexedDB에 별도 백업을 둡니다. 저장 데이터를 읽지 못하면 원본을 보관하고 자동으로 새 모델을 덮어쓰지 않습니다. 다른 탭에서 더 최신 기록을 저장하면 오래된 탭이 덮어쓰지 않도록 중지합니다. PC와 모바일은 각각 독립된 학습 기록을 유지합니다. 브라우저 저장 데이터를 지우면 학습 결과도 사라질 수 있으니 필요하면 모델 파일을 저장하세요.

하나의 통합 모델과 전체·과제별 시도 횟수를 이 브라우저에 저장합니다. 파일로 다른 기기에 옮길 수도 있습니다. 이전 보정형 v2 모델은 보관하며 이전 학습 기록 저장으로 내려받을 수 있습니다. 이전 보정형 v2는 새 직접 제어 방식과 호환되지 않아 보관만 합니다. 직접 제어 v3 모델은 새 목표 입력의 영향만 0으로 추가해 기존 가중치와 학습 횟수를 이어갑니다. 전체 초기화를 확인하면 이전 백업도 삭제됩니다.
