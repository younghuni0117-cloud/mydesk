격투 실행

두 로봇은 동일한 통합 모델과 신체 조건을 사용합니다. 체력 소진 또는 다운 10카운트로 승패를 판정합니다. 1카운트는 2초이며, 다운 중에도 공격할 수 있습니다.

통합 모델 실행 중에는 바로 적용합니다. 최근 모델 관찰 중에는 다음 통합 실행에 적용합니다. 위치는 출발점 0m 기준입니다.

상세 옵션
학습 방식

한 번의 학습 시도에서 진행할 최대 가상 시간입니다. 1~120초로 설정합니다. 균형 단계 학습은 2초 → 4초 → 설정 시간 순이며 설정값을 넘지 않습니다. 조기 종료를 켜면 더 짧게 끝날 수 있습니다. 검증·모델 실행 시간은 별도입니다.

균형잡기에 적용합니다. 조기 종료를 끄면 모든 시도를 끝까지 진행합니다. 전체 시간은 현재 단계의 2초·4초 또는 1회 학습 시간 설정값이며, 설정값보다 길어지지 않습니다. 주기마다 마지막 1회를 끝까지 진행합니다.

일어나기 · 성공 조건 및 보조력

켜면 보조력을 받지 않고 2초간 안정적으로 선 뒤 성공으로 학습 시도를 마칩니다. 끄면 설정한 학습 시간까지 진행합니다. 검증·통합 모델 실행에는 적용하지 않습니다.

누운 채 1.2초 이상 머물면 선택한 부위를 위로 당깁니다. 어깨는 어깨 연결부, 배는 몸통 하단에 힘을 가하며 캐릭터가 회전해도 적용점은 몸을 따라갑니다. 힘은 부드럽게 커지고 몸이 올라오면 줄어듭니다. 0 N 또는 0초는 끄기입니다. 시간은 시도마다 보조를 시작한 시점부터 최대 20초이며 다시 시작하지 않습니다. 일어나 2초 이상 안정적으로 선 채 시도를 마치면 자동 감소를 켠 항목을 힘 1 N·시간 0.01초씩 줄여 최종 0으로 만듭니다. 4회마다 1회는 보조 없이 학습합니다. 검증·통합 모델 실행에는 보조력이 없습니다. 학습 보상에는 보조를 받은 시도도 포함되므로 스스로 일어나는 성능은 검증 결과로 확인하세요. 자동 줄이기를 끄면 입력한 최대 힘을 사용합니다.

통합 학습

선택 운동만 반복하거나, 선택 운동부터 일곱 운동을 같은 횟수로 순서대로 학습하거나, 매 시도 운동을 무작위로 선택합니다. 모든 경험은 하나의 PPO 모델에 모입니다.

격투 훈련

샌드백 무게는 펀치·발차기 학습·검증·실행에 적용됩니다. 무게를 바꾸면 같은 충격에도 흔들림과 반동이 달라집니다. 나무 지지대는 장식이며 충돌 대상이 아닙니다.

펀치·발차기: 매달린 샌드백. 방어: 양쪽에서 높이·속도·간격이 달라지는 주먹(1.5~7m/s)을 막거나 피합니다. 격투: 두 로봇이 함께 대련합니다. 모든 경험은 같은 PPO 모델에 모이며 공격·방어·기상 동작은 미리 지정하지 않습니다.

관절 제어 · 각도 / 속도 / 토크

두 속도는 목표값의 상한입니다(최대 5000°/초). 추가 토크는 최대 100%까지 허용하지만 PD 토크와 합산한 최종 출력은 모터 최대 토크에서 제한됩니다. 큰 값은 더 급한 동작·진동·넘어짐을 늘릴 수 있습니다.

작을수록 목표 각도가 천천히 바뀝니다. 강도와 변화속도는 모델과 함께 저장·공유하며 학습·검증·실행에 동일하게 적용합니다. 변경하면 성능을 다시 평가합니다. 각도·회전속도·추가 토크를 모델이 학습합니다. 추가 토크는 PD 토크에 합산하고 최종 모터 한도를 적용합니다. 추가 토크 0%는 보정 출력을 사용하지 않습니다.

검증 · 추가 시험

검증 시간은 후보와 통합 모델을 같은 조건으로 비교합니다. 추가 시험은 개선된 통합 모델에만 여러 방향·세기의 밀기를 반복하며 진행합니다.

반복 타격은 시도 시작 후 약 1초부터 지정한 간격으로 발생합니다. 학습·최근 모델 관찰에 적용하며 검증은 고정 조건을 사용합니다.

환경 · 화면
강화학습 훈련소

훈련소를 선택했을 때만 적용됩니다. 지형·질량은 시도 시작 시 정해지고 도중에는 유지됩니다. 아홉 지형을 동일한 빈도로 섞어 경험합니다.

돌길에서 지정 범위 안의 높이를 무작위로 고릅니다. 폭도 높이에 비례해 달라집니다. 단계별 학습 초기에는 작은 돌부터 경험합니다.

경사·높이는 최댓값, 마찰·질량은 무작위 범위입니다. 영상 아래에는 현재 실제 적용값을 표시합니다. 단계별 학습을 켜면 시작 단계에서 경사·높이·마찰 범위·질량 변화와 외력 세기를 줄입니다. 통합 모델 실행에는 단계 축소 없이 설정한 범위를 적용하며 자동 외력은 가하지 않습니다. 이 외력 설정은 훈련소 전용이며 다른 지형은 자동 밀기 설정을 사용합니다.

모델 실행 · 관찰
그래프 기록

학습 평균은 선택 운동의 최근 20회(초기에는 완료한 횟수)의 실제 시도 보상입니다. 검증 보상은 고정 시험을 마친 뒤 갱신되며 모델 채택 판단에 사용합니다. 학습 평균 상승이 통합 모델의 성능 향상을 확정하지는 않습니다.

캐릭터 선택

탐험가·깡통 로봇·스타워즈형·등산객·김도윤·임선아 중 캐릭터를 선택할 수 있습니다. 외형만 바뀌고 관절·물리 조건·학습 모델은 같은 로봇을 유지합니다. 선택한 외형은 이 기기에 저장됩니다.

김도윤·임선아는 상C 작가의 《44교시 생존수업》 캐릭터를 단순화해 직접 그린 팬 스킨입니다.

7개 능력을 배우는 통합 모델

균형 잡기·일어나기·걷기·펀치·발차기·방어·격투를 하나의 PPO 정책으로 학습합니다. 장애물 통과 과제는 제거했습니다. 13개 강체·12개 관절, 몸 상태·이전 행동·7개 과제·상대 정보와 지형 센서 총 141개 입력 → 은닉 24개 → 목표 각도·속도·추가 토크 36개 출력을 사용합니다. 이전 구조의 학습 결과는 초기화합니다.

일어나기 시작 자세와 보상

초반에는 앉기·무릎 꿇기·웅크리기와 적은 비율의 앞뒤 누운 자세를 무작위로 섞습니다. 관절·몸 위치를 처음에만 배치하고 움직임이나 일어서는 순서는 지정하지 않습니다. 실제 성공률이 오르면 누운 자세 비율을 약 10%에서 최대 75%까지 늘립니다. 단계별 학습을 끄면 누운 자세 60%를 포함해 섞습니다. 검증은 앉기·무릎 꿇기·앞뒤 누운 자세의 고정 조건으로 비교합니다. 높이 비율 × 직립도 개선량을 보상해 허리 젖히기로 높이만 얻는 행동을 줄입니다. 허리·고관절 한계 부근만 작게 감점하며 일어나기에서는 토크·동작 부드러움 등의 추가 비용을 제외합니다.

훈련 상대와 방어

펀치·발차기는 물리적으로 매달린 샌드백을 칩니다. 방어는 머리·몸통 높이와 좌우 방향, 1.5~7m/s 속도·간격이 무작위인 주먹을 상대합니다. 실제 충돌로 힘과 피해를 전달하며 팔·다리로 막은 접촉은 피해를 줄이고 막기 보상을 줍니다. 몸을 움직여 피하면서 서 있는 상태를 유지해야 회피 보상을 받습니다. 주먹 장치는 환경 자극이며 로봇의 가드·회피 자세는 지정하지 않습니다. 격투 과제에는 항상 두 로봇이 등장합니다. 통합 모델의 격투 실행에서는 양쪽 모두 같은 가중치를 사용하고, 학습 상대는 현재 또는 과거 통합 모델을 사용합니다.

고속 타격과 경기

약공격·강공격 애니메이션은 없습니다. 같은 관절 제어가 실제 접촉 속도와 충격량을 만들며, 전달된 충격과 맞은 부위로 피해를 계산합니다. 모터의 토크·속도 한계, 반동과 에너지 비용을 적용합니다. 격투에서는 연속 충돌 검사와 1/720초 물리 하위 스텝을 사용합니다. 2D의 좌우 팔다리는 같은 평면에 투영되며 자기 몸끼리의 충돌은 제외합니다.

체력은 기본 100이며 유효 타격으로 소진되면 패배합니다. 다운 카운트는 시뮬레이션 시간 2초당 1씩 증가하고 10이면 패배합니다. 몸통 접촉 또는 낮은 골반이 0.25초 이어지면 다운, 발로 지지하며 1초 안정적으로 서면 카운트를 해제합니다. 다운 중 공격을 막는 규칙은 없습니다. 동시 패배는 무승부, 시간 종료는 남은 체력과 유효 피해로 판정합니다. 캐릭터는 외형만 다르고 체격·모터와 가중치는 동일합니다.

균등한 시각 센서

머리에 연결된 최대 3.2m 시야에 좌우 경로 각각 17개, 총 34개 감지선을 같은 각도 간격으로 배치했습니다. 상·하단을 나누지 않습니다. 실제 충돌 위치의 원은 회색이며, 감지 막대 선과 각도 숫자는 표시하지 않습니다. 지형과 만나는 실제 점의 공간 간격은 지형 높이와 거리에 따라 달라집니다.

스스로 다음 동작을 배우는 탐색

기본 자세·보행 주기·발 들기·자동 일어서기 동작은 없습니다. 초기 통합 정책의 모터 출력은 0입니다. PPO는 이전보다 큰 초기 탐색과 최소 탐색 폭, 더 긴 미래 보상 반영을 사용합니다. 걷기에서는 한 행동을 0.1초 유지하며 그 결과를 학습합니다. CEM도 일부 시도에서 여러 관절을 함께 탐색합니다. 실제로 앞으로 나가도록 배워야 보상을 얻으며, 학습 성공을 보장하지는 않습니다.

명령·목표 설정

상세 옵션 위의 명령·목표 설정은 기본적으로 접혀 있습니다. 제자리 유지·계속 이동·목표 위치로 이동, 앞뒤 방향·속도·낮은 자세를 선택합니다. 통합 모델 실행 중 변경하면 몸·속도·관찰시간을 초기화하지 않고 목표만 바꿉니다. 지형에서 목표 선택을 켠 다음 화면을 누르면 그 위치로 지정합니다. 선택 중 다시 버튼을 누르면 취소합니다. 제자리 유지는 현재 위치에 머물라는 목표이며 물리 동작을 강제로 멈추지 않습니다. 낮은 자세도 관절 각도를 지정하는 동작이 아닙니다. 충분히 학습되지 않으면 명령을 수행하지 못할 수 있습니다.

균형은 제자리 유지에 집중하며, CEM은 같은 정책을 좌우 기울기 두 조건에서 비교합니다. 다른 운동도 한 묶음 안에서 같은 목표 조건을 경험합니다. 기본 운동, 뒤로 이동 후 정지·왕복·위치 도착, 낮은 자세와 사용자가 선택한 목표를 순환해 학습합니다. 실행 중 목표가 바뀌거나 넘어져도 관절 동작은 같은 신경망이 정하며 자동 일어서기 동작은 없습니다. 통합 모델 채택에는 기존 일곱 운동 능력의 검증과 별도의 고정된 명령 시험 보상을 함께 사용합니다. 표·그래프는 기존 운동별 네 조건 검증 값이며 명령 시험 점수는 합산하지 않습니다.

PPO와 단계별 학습

각 행동의 보상과 미래 가치를 이용해 하나의 정책과 가치 함수를 갱신합니다. 검증을 거쳐 개선된 정책을 통합 모델로 채택합니다. 균형은 2초·4초·설정 시간으로 늘릴 수 있으며, 각 과제별 학습·검증·실행 시간은 상세 옵션에서 변경합니다. 격투 자동 훈련은 샌드백·움직이는 샌드백·제한 대련·자유 대련으로 확장합니다. 과거 통합 모델 최대 3개를 훈련 상대로 사용하며, 실제 경기 실행은 양쪽이 같은 현재 통합 모델을 사용합니다. 기초 균형과 기상도 스스로 학습해야 하며 학습 성공이나 사람 수준의 격투를 보장하지 않습니다.

상점·벌점 기준

아래 값은 실제 보상 계산과 같은 설정에서 표시합니다. 초당 점수는 물리 시간에 비례해 누적합니다. 표의 평균 보상은 고정된 네 조건에서 받은 누적 점수의 평균입니다. 이전에 통과한 검증 조건이나 숙련 능력의 보존 기준을 벗어난 후보는 남은 검증을 생략합니다. 아직 평가하지 않은 능력의 후보 점선은 비워 두며, 통합 모델 채택 전에는 모든 검증을 마칩니다. 선택 운동의 검증 통과율·실제 운동 성능·보상 순으로 개선을 비교하며, 균형은 가장 약한 검증 조건과 평균 서 있는 시간을 자세 품질 점수보다 먼저 비교합니다. 또한 이미 통과한 다른 능력의 조건도 보존합니다. 개선된 통합 모델만 별도의 두 조건에서 장기 추가 시험을 진행합니다. 기본 30초이며 상세 옵션에서 검증 시간 이상인 10~3600초로 변경합니다. 방향·세기·작용 부위와 시점을 바꾼 반복 밀기를 사용하고, 결과는 모델 선택이나 학습 보상에 합산하지 않습니다.

모든 운동 능력의 공통 상점·벌점

밀려도 버티는 학습

상세 옵션에서 학습 전에 자동 밀기를 켜면 적용 단계의 각 시도에 무작위 방향으로 머리·몸통·골반·양팔·손·허벅지·종아리·발 중 한 부위를 미는 타격을 예약합니다. 기본은 시도당 1회이고 상세 옵션의 망치 빈도로 반복 간격을 설정할 수 있습니다. 관찰에는 힘에 따라 크기·휘두름이 달라지는 망치가 나타났다가 사라집니다. 그림은 실제 밀기와 같은 시점·부위를 표시하며 추가 힘을 가하지 않습니다. 균형 학습이 넘어짐으로 먼저 끝나면 그 시도의 밀기는 실행되지 않을 수 있습니다. 상세 옵션에서 세기의 최솟값·최댓값을 0.1~100 N·s 범위로 정합니다. 처음 값은 1~6 N·s입니다. 최근 모델 관찰에서도 해당 시도의 밀기를 재현합니다. 통합 모델 실행은 자동으로 밀지 않으며 마우스로 직접 시험할 수 있습니다. 직접 밀기는 학습에 포함되지 않습니다. 밀림에 대한 적응을 연습하지만 모든 외력을 견딘다는 보장은 아닙니다. 표의 검증은 설정과 별개로 동일한 정지·외력 조건에서 평가합니다.

화면의 상벌점 표시

파란 숫자는 보상, 빨간 숫자는 벌점입니다. 표시할 합계가 +1 이상 또는 −1 이하인 경우에만 작은 글씨로 표시합니다. 지속적으로 계산되는 점수는 첫 0.2초 이후 2초씩 모아 로봇 몸 바깥에 표시하며, 넘어짐·충돌·회복·통과와 시도 종료는 바로 표시합니다. 한 번에 보상 하나와 벌점 하나까지 띄워 겹침과 빈도를 줄입니다. 보상과 벌점은 상쇄하지 않고 따로 띄웁니다. 시야는 머리, 지지는 발, 이동은 골반, 말단 비용은 해당 관절, 충돌은 실제 접촉 위치에 표시합니다. 전신 자세와 제어 비용은 몸통에 표시합니다. 숫자는 읽기 편하게 반올림하며 실제 학습 점수는 바꾸지 않습니다.

과정 로그

왼쪽 아래 로그에는 학습 계산, 후보·전체 검증, 추가 시험, 모델 갱신과 화면 재생을 구분해 기록합니다. 실제 적용된 밀기의 부위·방향·충격량은 N·s로 표시합니다. N·s는 힘 자체가 아니라 짧은 시간 동안 가한 충격량입니다. 로그는 최근 160줄을 유지하며 이전 기록을 읽는 동안 자동 스크롤을 멈춥니다. 상세 옵션의 로그 표시·기록을 끄면 창을 숨기고 새 기록 생성과 로그 갱신도 중지합니다. 다시 켜면 현재 과정부터 기록하며 숨긴 동안의 내용을 추가하지 않습니다.

실제 물리와 관찰

보조 지지력 없이 13개 강체·12개 회전 관절을 계산합니다. 신경망이 12개 관절의 목표 각도·목표 회전속도·추가 토크, 총 36개 출력을 정합니다. PD 제어기가 각도 오차와 속도 오차를 보정하고 추가 토크를 합산한 뒤 모터 한도를 적용합니다. 이전 행동과 운동 명령도 관찰에 포함합니다. 목표 각도는 관절 가동 범위 안에 제한하며 기존 최대 토크·속도 한계를 유지합니다. 목표는 걷기에서 초당 10회, 다른 과제에서 20회 갱신합니다. 실제 추종 목표에는 최대 변화속도를 적용하고 토크는 매 물리 하위 스텝에서 보정합니다. 관절 반응 강도와 변화속도는 상세 옵션에서 정하며 모델과 함께 공유합니다. 무릎·팔꿈치는 양쪽 탐색 출력을 허용된 굽힘 방향으로 사용하고, 새 탐색 폭은 관절별 각도 범위에 맞춰 조정합니다. 새 정책의 출력 0은 상대 관절 각도 0을 뜻하며 서 있기나 보행을 학습했다는 뜻이 아닙니다. 걷기·일어서기 순서나 균형 회복 동작은 미리 넣지 않습니다. 물리적인 관절 각도 제한·마찰·질량·수동 허리 탄성은 유지합니다. PD 제어기는 모델이 선택한 관절 각도를 추종하며 몸 전체를 자동으로 세우거나 다음 동작을 지정하지 않습니다. 각도·속도·토크 통합 정책으로 처음부터 학습합니다. 훈련소는 지형·마찰·질량을 시도마다 바꾸며, 고정 지형에는 이 무작위 변화를 적용하지 않습니다. 기본은 일곱 과제를 균등하게 순서대로 학습합니다. 통합 학습에서 선택 운동만 또는 무작위 학습으로 바꿀 수 있습니다. 검증은 학습과 다른 고정 지형 묶음으로 비교하고 개선된 모델은 별도 조건으로 추가 시험합니다. 이전 토크 모델·보관본·과거 학습 횟수·그래프를 가져오지 않습니다. 모든 운동 과제는 같은 새 통합 모델을 사용합니다. 관절 한계와 실제 모터의 힘·속도 한계는 물리 조건으로 적용합니다. 관절이 거의 펴졌다는 이유로 모터 힘을 0으로 만들지 않으며 실제 각도 제한은 물리 관절이 지킵니다. 1회는 기본 최대 10초의 가상 시간이며 상세 옵션에서 1~120초로 바꿀 수 있습니다. 단계별 균형 학습은 2초·4초·설정한 1회 학습 시간으로 진행하며 설정값을 넘지 않고 균형을 잃은 상태가 지속되면 먼저 끝날 수 있습니다. 검증·재생은 횟수에 합산하지 않습니다. 기본 그래프는 선택한 운동 과제의 최근 20회 학습 평균을 매 시도 종료마다 갱신합니다. 초기에는 완료한 시도만 평균 내며 학습 지형이나 최대 시도 시간이 달라지면 평균 구간을 새로 시작합니다. 추가 물리 시험 없이 이미 계산한 보상을 사용합니다. 상세 옵션의 표시할 보상에서 기존 통합·최근 모델 검증 그래프로 전환할 수 있습니다. 표의 검증 보상은 통합 모델의 고정 시험 결과로 학습 평균과 구분합니다. 가로축은 선택한 운동 능력의 0회부터 현재 학습 횟수까지이며, 다른 운동 능력의 횟수는 합산하지 않습니다. 이전 버전에 과제별 횟수 기록이 없으면, 한 과제만 학습한 경우에만 과거 횟수를 복원합니다. 여러 과제가 섞인 구간은 새 평가부터 표시합니다. 학습 중에는 최근 모델이 실제 시도에서 만든 움직임을 부드럽게 재생하여 중복 물리 계산을 줄입니다. 직접 밀기나 통합 모델 실행은 실시간 물리로 시험합니다. 중간 관찰은 최근 모델을 다시 실행하고, 통합 모델 실행은 검증을 거쳐 저장한 가중치로 시험합니다. 상세 옵션에서 모델 실행 시간을 1~3600초로 정하고 갱신 간격도 바꿀 수 있습니다. 모델 실행 시간은 학습·검증 시도의 길이에 영향을 주지 않습니다. 화면의 경과 시간은 현재 시도의 진행 시간입니다.

마우스 왼쪽 버튼으로 로봇을 잡아 드래그하면 놓는 방향과 거리에 따라 밀립니다. 오른쪽 버튼으로 드래그하면 화면을 이동하고 휠로 확대·축소합니다. 터치는 한 손가락으로 로봇을 밀고 두 손가락으로 이동·확대합니다. 기본은 지형 고정이며 보기 선택에서 로봇 중심으로 바꿀 수 있습니다. 학습은 현재 기기의 CPU에서 실행됩니다. 학습 로봇은 한 대로 실행합니다. 검증 조건과 물리 계산 간격은 그대로 유지합니다. 관찰은 화면 주사율에 맞춰 보간하며 모바일에서는 렌더링 해상도를 조절합니다. 창이 숨겨지면 학습 중지를 요청합니다.

공용 모델 자동 공유

PC와 모바일 모두 로그인 없이 하나의 공개된 로봇 모델을 사용합니다. 홈페이지를 열거나 학습을 시작할 때 최신 모델을 불러오고, 학습 중에는 최대 30초 간격으로 완료된 계산 결과를 공유합니다. 학습 완료·중지 때도 자동 저장합니다. 학습하지 않을 때에는 15초마다 변경을 확인합니다. 다른 기기에서 학습한 가중치·학습 횟수·그래프를 함께 이어받습니다.

누구나 공용 모델을 덮어쓸 수 있으며 마지막 저장 결과가 적용됩니다. 두 기기의 학습 결과를 합치지는 않습니다. 학습 중에는 현재 기기의 학습을 유지하고, 완료 후 그 결과를 공용 모델에 저장합니다. 상세 옵션의 초기화는 모든 기기가 공유하는 모델에 적용됩니다. 백업·복원 기록은 만들지 않습니다.

네트워크 연결이 끊기면 현재 기기의 최신 상태만 임시 저장하고 다시 연결되면 자동으로 공유합니다. 창을 닫기 전 학습을 중지하고 공용 모델 저장 완료 표시를 확인하세요. 캐릭터·보기·관찰시간 등 화면 설정은 각 기기에 따로 유지됩니다. 업데이트 전 로컬 학습 기록은 공용 모델이 비어 있을 때 첫 접속 기기에서 이어받습니다.
