로봇 안내·저장

캐릭터 선택

탐험가·깡통 로봇·스타워즈형·등산객·김도윤·임선아 중 캐릭터를 선택할 수 있습니다. 외형만 바뀌고 관절·물리 조건·학습 모델은 같은 로봇을 유지합니다. 선택한 외형은 이 기기에 저장됩니다.

김도윤·임선아는 상C 작가의 《44교시 생존수업》 캐릭터를 단순화해 직접 그린 팬 스킨입니다.

12개 관절의 새 로봇

손목과 발앞꿈치 관절을 제거했습니다. 손은 팔뚝, 발끝은 발의 단단한 일부이며 질량과 외형은 유지합니다. 13개 강체·12개 관절, 상태/목표 입력 39개와 지형 입력 26개, 총 65개 입력 → 은닉 12개 → 실제 모터 12개, 가중치 1,020개를 사용합니다. 이전 모델과 구조가 달라 새 모델로 초기화했습니다.

균등한 시각 센서

머리에 연결된 최대 3.2m 시야에 좌우 경로 각각 17개, 총 34개 감지선을 같은 각도 간격으로 배치했습니다. 상·하단을 나누지 않습니다. 실제 충돌 위치의 원은 회색이며, 감지 막대 선과 각도 숫자는 표시하지 않습니다. 지형과 만나는 실제 점의 공간 간격은 지형 높이와 거리에 따라 달라집니다.

스스로 다음 동작을 배우는 탐색

기본 자세·보행 주기·발 들기·자동 일어서기 동작은 없습니다. 초기 통합 정책의 모터 출력은 0입니다. PPO는 이전보다 큰 초기 탐색과 최소 탐색 폭, 더 긴 미래 보상 반영을 사용합니다. 걷기·달리기에서는 한 행동을 0.1초 유지하며 그 결과를 학습합니다. CEM도 일부 시도에서 여러 관절을 함께 탐색합니다. 실제로 앞으로 나가도록 배워야 보상을 얻으며, 학습 성공을 보장하지는 않습니다.

명령·목표 설정

상세 옵션 위의 명령·목표 설정은 기본적으로 접혀 있습니다. 제자리 유지·계속 이동·목표 위치로 이동, 앞뒤 방향·속도·낮은 자세를 선택합니다. 통합 모델 실행 중 변경하면 몸·속도·관찰시간을 초기화하지 않고 목표만 바꿉니다. 지형에서 목표 선택을 켠 다음 화면을 누르면 그 위치로 지정합니다. 선택 중 다시 버튼을 누르면 취소합니다. 제자리 유지는 현재 위치에 머물라는 목표이며 물리 동작을 강제로 멈추지 않습니다. 낮은 자세도 관절 각도를 지정하는 동작이 아닙니다. 충분히 학습되지 않으면 명령을 수행하지 못할 수 있습니다.

균형은 제자리 유지에 집중하며, CEM은 같은 정책을 좌우 기울기 두 조건에서 비교합니다. 다른 운동도 한 묶음 안에서 같은 목표 조건을 경험합니다. 기본 운동, 뒤로 이동 후 정지·왕복·위치 도착, 낮은 자세와 사용자가 선택한 목표를 순환해 학습합니다. 실행 중 목표가 바뀌거나 넘어져도 관절 동작은 같은 신경망이 정하며 자동 일어서기 동작은 없습니다. 통합 모델 채택에는 기존 다섯 운동 능력의 검증과 별도의 고정된 명령 시험 보상을 함께 사용합니다. 표·그래프는 기존 운동별 네 조건 검증 값이며 명령 시험 점수는 합산하지 않습니다.

학습 방식·난이도

상세 옵션에서 개선 CEM과 PPO를 선택합니다. CEM은 32회 묶음으로 탐색합니다. 균형에서는 정책 16개를 좌우 초기 기울기로 각각 시험하고, 실제로 서 있던 시간을 우선해 다음 탐색을 정합니다. 기본 균형에서는 출력층부터 학습하며 기초가 잡히면 입력 특징도 조정합니다. 4,096회 동안 개선이 없을 때 탐색을 재조정해 너무 잦은 재시작을 피합니다. PPO는 각 행동과 이후 보상으로 정책과 가치 함수를 갱신합니다. 보통 8회 단위로 확인하고 경험이 256개 이상 모이면 갱신합니다(요청 종료 시 최소 64개). 균형은 실패 후 긴 데이터에 치우치지 않도록 짧은 실패 시도와 8회 중 한 번의 전체 시도를 섞습니다. 새 탐색 정책은 출력층을 0으로 두고 입력 특징만 초기화하며, 초기 탐색 잡음도 작게 시작합니다. CEM/PPO를 바꿀 때 기존 탐색 정책이 현재 통합 모델보다 뒤처지면 이전 상태를 보관하고 통합 모델에서 재개합니다. PPO도 2,048회 이상 통합 모델 개선이 없고 현재 탐색 정책이 뒤처지면 통합 모델로 돌아가 작은 탐색 폭을 재조정합니다. 가치 함수는 이어가고 이전 탐색 상태는 보관합니다. 두 방식 모두 하나의 통합 모델을 사용하고 학습 횟수는 실제 시도로 셉니다. PPO가 항상 더 좋은 결과를 보장하는 것은 아닙니다.

단계별 학습을 켜면 균형은 2초 기초 → 4초 유지 → 설정한 검증 시간 연습으로 늘립니다. 외력 없는 검증의 최장 유지 시간이 1.5초·3.5초를 넘으면 다음 단계로 진행하며 학습 중 검증 시간의 기본값은 10초이며 상세 옵션에서 6~120초로 변경합니다. 2초·4초 단계는 자동 밀기를 체크해도 외력 없이 기본 균형을 익히고, 최종 단계부터 설정한 범위의 밀기를 적용합니다. 단계별 학습을 끄면 처음부터 설정한 외력 조건을 적용합니다. 균형에는 이동·낮은 자세 명령을 섞지 않습니다. 다른 운동은 기본 운동을 먼저 익힌 뒤 명령 변경을 연습합니다. 설정한 밀기 최소·최대 범위 안에서 약한 쪽부터 시작해, 검증 성능이 좋아질수록 상한과 초기 흔들림을 높입니다. 검증의 밀기 세기는 고정되어 있습니다. 미숙한 능력의 점수는 탐색 중 변할 수 있지만, 이전에 통과한 검증 조건을 잃은 후보는 통합 모델로 채택하지 않습니다.

상점·벌점 기준

아래 값은 실제 보상 계산과 같은 설정에서 표시합니다. 초당 점수는 물리 시간에 비례해 누적합니다. 표의 평균 보상은 고정된 네 조건에서 받은 누적 점수의 평균입니다. 이전에 통과한 검증 조건이나 숙련 능력의 보존 기준을 벗어난 후보는 남은 검증을 생략합니다. 아직 평가하지 않은 능력의 후보 점선은 비워 두며, 통합 모델 채택 전에는 모든 검증을 마칩니다. 선택 운동의 검증 통과율·실제 운동 성능·보상 순으로 개선을 비교하며, 균형은 가장 약한 검증 조건과 평균 서 있는 시간을 자세 품질 점수보다 먼저 비교합니다. 또한 이미 통과한 다른 능력의 조건도 보존합니다. 개선된 통합 모델만 별도의 두 조건에서 장기 추가 시험을 진행합니다. 기본 30초이며 상세 옵션에서 검증 시간 이상인 10~3600초로 변경합니다. 방향·세기·작용 부위와 시점을 바꾼 반복 밀기를 사용하고, 결과는 모델 선택이나 학습 보상에 합산하지 않습니다.

모든 운동 능력의 공통 상점·벌점

밀려도 버티는 학습

상세 옵션에서 학습 전에 자동 밀기를 켜면 적용 단계의 각 시도에 무작위 방향으로 머리·몸통·골반·양팔·손·허벅지·종아리·발 중 한 부위를 미는 타격을 예약합니다. 기본은 시도당 1회이고 상세 옵션의 망치 빈도로 반복 간격을 설정할 수 있습니다. 관찰에는 힘에 따라 크기·휘두름이 달라지는 망치가 나타났다가 사라집니다. 그림은 실제 밀기와 같은 시점·부위를 표시하며 추가 힘을 가하지 않습니다. 균형 학습이 넘어짐으로 먼저 끝나면 그 시도의 밀기는 실행되지 않을 수 있습니다. 상세 옵션에서 세기의 최솟값·최댓값을 0.1~30 N·s 범위로 정합니다. 처음 값은 1~6 N·s입니다. 최근 모델 관찰에서도 해당 시도의 밀기를 재현합니다. 통합 모델 실행은 자동으로 밀지 않으며 마우스로 직접 시험할 수 있습니다. 직접 밀기는 학습에 포함되지 않습니다. 밀림에 대한 적응을 연습하지만 모든 외력을 견딘다는 보장은 아닙니다. 표의 검증은 설정과 별개로 동일한 정지·외력 조건에서 평가합니다.

화면의 상벌점 표시

초록 숫자는 보상, 빨간 숫자는 벌점입니다. 표시할 합계가 +1 이상 또는 −1 이하인 경우에만 작은 글씨로 표시합니다. 지속적으로 계산되는 점수는 1초씩 모아 로봇 몸 바깥에 표시하며, 넘어짐·충돌·회복·통과와 시도 종료는 바로 표시합니다. 보상과 벌점은 상쇄하지 않고 따로 띄웁니다. 시야는 머리, 지지는 발, 이동은 골반, 말단 비용은 해당 관절, 충돌은 실제 접촉 위치에 표시합니다. 전신 자세와 제어 비용은 몸통에 표시합니다. 숫자는 읽기 편하게 반올림하며 실제 학습 점수는 바꾸지 않습니다.

실제 물리와 관찰

보조 지지력 없이 13개 강체·12개 회전 관절을 계산합니다. 신경망이 관절에 가할 토크를 직접 정합니다. 새 탐색 정책은 센서 특징을 초기화하되 출력층은 0으로 시작합니다. 이 초기화는 관절 목표 자세나 동작을 지정하지 않습니다. 물리적인 관절 각도 제한·마찰·질량·수동 허리 탄성은 유지하지만 자동 자세 교정이나 기본 운동 동작은 없습니다. 관절 한계와 실제 모터의 힘·속도 한계는 물리 조건으로 적용합니다. 관절이 거의 펴졌다는 이유로 모터 힘을 0으로 만들지 않으며 실제 각도 제한은 물리 관절이 지킵니다. 1회는 기본 최대 10~12초의 가상 시간입니다. 단계별 균형 학습은 2초·4초·설정한 검증 시간으로 진행하며 균형을 잃은 상태가 지속되면 먼저 끝날 수 있습니다. 검증·재생은 횟수에 합산하지 않습니다. 그래프는 선택한 운동 과제의 실제 평균 보상이며 표의 해당 행과 같은 값입니다. 가로축은 선택한 운동 능력의 0회부터 현재 학습 횟수까지이며, 다른 운동 능력의 횟수는 합산하지 않습니다. 이전 버전에 과제별 횟수 기록이 없으면, 한 과제만 학습한 경우에만 과거 횟수를 복원합니다. 여러 과제가 섞인 구간은 새 평가부터 표시합니다. 학습 중에는 최근 모델이 실제 시도에서 만든 움직임을 부드럽게 재생하여 중복 물리 계산을 줄입니다. 직접 밀기나 통합 모델 실행은 실시간 물리로 시험합니다. 중간 관찰은 최근 모델을 다시 실행하고, 통합 모델 실행은 검증을 거쳐 저장한 가중치로 시험합니다. 상세 옵션에서 관찰시간을 1~3600초로 정하고 갱신 간격도 바꿀 수 있습니다. 관찰시간은 학습·검증 시도의 길이에 영향을 주지 않습니다.

마우스 왼쪽 버튼으로 로봇을 잡아 드래그하면 놓는 방향과 거리에 따라 밀립니다. 오른쪽 버튼으로 드래그하면 화면을 이동하고 휠로 확대·축소합니다. 터치는 한 손가락으로 로봇을 밀고 두 손가락으로 이동·확대합니다. 기본은 지형 고정이며 보기 선택에서 로봇 중심으로 바꿀 수 있습니다. 학습은 현재 기기의 CPU에서 실행됩니다. 코어가 4개 이상으로 보고되는 환경에서는 최대 두 후보를 동시에 계산합니다. 결과는 원래 시도 순서대로 반영하며, 병렬 실행을 지원하지 않거나 실패하면 순차 계산으로 이어갑니다. 검증 조건과 물리 계산 간격은 그대로 유지합니다. 관찰은 화면 주사율에 맞춰 보간하며 모바일에서는 렌더링 해상도를 조절합니다. 창이 숨겨지면 학습 중지를 요청합니다.

공용 모델 자동 공유

PC와 모바일 모두 로그인 없이 하나의 공개된 로봇 모델을 사용합니다. 홈페이지를 열거나 학습을 시작할 때 최신 모델을 불러오고, 학습 중에는 최대 30초 간격으로 완료된 계산 결과를 공유합니다. 학습 완료·중지 때도 자동 저장합니다. 학습하지 않을 때에는 15초마다 변경을 확인합니다. 다른 기기에서 학습한 가중치·학습 횟수·그래프를 함께 이어받습니다.

누구나 공용 모델을 덮어쓸 수 있으며 마지막 저장 결과가 적용됩니다. 두 기기의 학습 결과를 합치지는 않습니다. 학습 중에는 현재 기기의 학습을 유지하고, 완료 후 그 결과를 공용 모델에 저장합니다. 상세 옵션의 초기화는 모든 기기가 공유하는 모델에 적용됩니다. 백업·복원 기록은 만들지 않습니다.

네트워크 연결이 끊기면 현재 기기의 최신 상태만 임시 저장하고 다시 연결되면 자동으로 공유합니다. 창을 닫기 전 학습을 중지하고 공용 모델 저장 완료 표시를 확인하세요. 캐릭터·보기·관찰시간 등 화면 설정은 각 기기에 따로 유지됩니다. 업데이트 전 로컬 학습 기록은 공용 모델이 비어 있을 때 첫 접속 기기에서 이어받습니다.
