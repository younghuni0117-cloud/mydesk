01 · OVERVIEW

PhysicsNeMo란?

NVIDIA의 PyTorch 기반 오픈소스 물리 AI 프레임워크입니다. 수치해석·실험 데이터와 물리 지식을 활용해 예측 모델을 만들고 학습·추론하는 도구를 제공합니다. 유동, 열, 구조역학 등 과학·공학 문제에 활용할 수 있습니다. [1]

구조해석에서의 핵심 역할

조건을 바꿀 때마다 계산하던 응답을 학습해, 반복적인 설계 탐색을 빠르게 돕는 대리모델(surrogate model)을 만들 수 있습니다. CAD와 하중을 넣기만 하면 모든 문제를 자동으로 해결하는 범용 FEM 해석기는 아닙니다.

무엇을 입력하나요?
좌표·메시·형상, 재료 특성, 하중, 경계조건과 초기 상태 등 문제를 정의하는 정보입니다.
무엇을 예측하나요?
변위·응력 같은 공간 분포나 시간에 따른 변형 등, 학습 목표로 정의한 응답입니다.
무엇을 직접 준비하나요?
데이터와 물리식, 모델 입력·출력, 손실함수, 학습 범위와 검증 기준입니다.

라이브러리는 Apache 2.0으로 공개되어 있습니다. 데이터·사전학습 모델·외부 솔버의 사용 조건은 각각 확인합니다. [2]

02 · METHODS

무엇을 보고 학습할까?

해석 결과를 정답으로 배우는 방식과 물리식을 만족하도록 배우는 방식, 두 가지를 함께 사용하는 방식이 있습니다. PhysicsNeMo를 쓴다는 이유만으로 모든 모델에 물리 법칙이 자동 적용되지는 않습니다. [3]

학습 방식 비교
접근학습에 사용하는 정보구조해석에서의 선택 기준
데이터 기반FEM·실험의 입력과 정답 응답신뢰할 수 있는 해석 데이터가 있고 같은 계열의 설계를 반복 검토할 때
물리 기반 · PINN평형식·재료식·경계조건의 잔차물리식이 명확한 문제에서 해를 근사하거나 미지의 물성을 추정할 때
혼합 방식정답 데이터 오차 + 물리 잔차데이터 정확도와 물리적 일관성을 함께 개선하려 할 때

입력 데이터의 형태에 맞는 모델

  • 소수의 설계 변수 → 대표 응답: 먼저 작은 회귀 모델로 최대 변위 같은 지표를 예측해 기준 성능을 만듭니다.
  • 비정형 메시 → 절점 응답: MeshGraphNet 같은 GNN을 검토합니다. 절점·요소 연결과 하중·구속 정보를 입력 특징으로 준비합니다.
  • 규칙 격자 → 응답장: FNO 같은 신경 연산자를 검토합니다. 원래 데이터가 비정형 메시라면 격자화 과정의 오차도 확인합니다.
  • 복잡한 형상·공간 상호작용: Transolver·GeoTransolver 계열도 후보입니다. 입력 특징과 메모리 비용, 보지 못한 형상에 대한 성능을 실제 데이터로 비교합니다.

모델 종류와 역할은 공식 개요 및 구조 동역학 레시피를 참고했습니다. 선택 기준은 이 문서의 적용 제안입니다. [1] [5]

03 · STRUCTURAL ANALYSIS

구조해석에는 어떻게 적용할까?

반복 설계의 빠른 응답 예측

형상 치수·두께·재료·하중의 범위를 정하고, 그 안에서 변위와 응력을 예측합니다. 후보 설계를 좁히는 단계에 활용하고 최종 후보는 기준 해석으로 다시 확인합니다.

물성·하중의 역추정

측정한 변위·변형률로 미지의 물성이나 하중을 추정하는 문제를 구성할 수 있습니다. 관측 정보가 부족하면 서로 다른 조건이 같은 응답을 만들 수 있으므로 식별 가능성을 먼저 검토합니다.

충돌·과도 구조응답

공식 충돌 사례는 FEM의 시간별 변형을 학습하는 접근을 제시합니다. 데이터 정리, 모델 선택, 시간 전개와 기준 해석 비교가 포함되며, 정적 선형탄성과는 별도의 데이터·검증이 필요합니다. [4]

선형탄성의 물리식과 학습 손실 살펴보기

작은 변형의 선형탄성 정적 문제를 예로 들면 변위 u에서 변형률 ε, 응력 σ를 정의하고 힘의 평형을 확인합니다.

변형률ε = ½ (∇u + ∇uᵀ)

재료식σ = C : ε

정적 평형∇·σ + b = 0

경계조건u = ū / σn = t̄

C는 탄성 텐서, b는 단위 체적당 힘, n은 경계의 법선입니다. 변위 지정 경계와 하중 지정 경계는 각각의 영역에 적용합니다. 예를 들어 학습 손실을 데이터 오차, 평형 잔차, 경계조건 오차, 재료식 오차의 가중 합으로 구성할 수 있습니다. 어떤 항이 필요한지는 출력 변수와 정식화에 따라 달라집니다. [6] [3]

평면응력과 평면변형률을 구분합니다. 얇은 판의 평면응력은 두께 방향 응력이 0인 가정입니다. 평면변형률은 두께 방향 변형률을 제한하며, 두께 방향 응력이 0이라는 뜻은 아닙니다.

길이·변위·응력의 단위와 정규화를 통일하고 손실항의 크기를 조절합니다. 접촉, 소성, 큰 변형과 재료 이력은 위 선형식만으로 설명할 수 없어 해당 지배식·상태 변수·데이터가 추가로 필요합니다.

공식 예제와 현재 API를 구분하세요.

구버전 PhysicsNeMo Sym 문서에는 3D 브래킷과 얇은 판 등의 선형탄성 예제가 있습니다. 현재 v2 계열에서는 핵심 기능이 physicsnemo.sym으로 통합되었고, 기존 LinearElasticity 같은 사전 정의 PDE 클래스는 그대로 제공되지 않습니다. 원리는 참고하되 코드는 사용 버전의 이관 가이드에 맞춰 작성합니다. [6] [7]

구조해석 데이터에서 챙길 항목

형상과 메시
좌표, 절점·요소 연결, 요소 종류, 두께, 단위와 좌표계. 형상이 달라질 때의 대응 방식도 정합니다.
조건과 재료
구속 위치·방향, 힘·압력·접촉 조건, 탄성계수·포아송비. 동역학에는 밀도·초기 조건·재료 이력 등도 포함합니다.
정답 필드
변위·응력·변형률의 위치와 성분을 명시합니다. 요소 적분점 값과 절점으로 평균한 값을 섞지 않고, 시간 간격도 맞춥니다.

기존 해석 프로그램의 출력은 필요한 필드를 추출해 모델 입력 형식으로 변환해야 합니다. 공식 충돌 레시피는 LS-DYNA의 d3plot을 Curator로 전처리한 VTP·Zarr 데이터를 다룹니다. 다른 솔버에도 같은 파일을 바로 넣을 수 있다는 뜻은 아니며, 데이터 리더와 변환 과정을 맞춰야 합니다. [5]

데이터 분리는 해석 케이스 단위로

하나의 해석에서 나온 절점이나 시간 프레임을 무작위로 나눠 학습·시험에 섞으면 실제 일반화 성능을 과대평가할 수 있습니다. 형상·재료·하중 조합을 기준으로 케이스 전체를 나누고, 같은 케이스의 메시와 시간 이력은 같은 묶음에 둡니다.

05 · FIRST PROJECT

첫 실험 제안: 외팔보 변위 예측

아래는 작은 규모로 시작하기 위한 학습 계획입니다. 공식 예제의 실행 결과나 이 홈페이지에서 계산한 해석 결과가 아닙니다.

  1. 범위 정하기

    선형탄성·작은 변형의 정적 문제로 시작합니다. 처음에는 형상·재료·고정 조건을 일정하게 두고, 하중만 바꿔 데이터와 예측의 연결을 확인합니다.

  2. 간단한 기준 해와 비교하기

    직사각형 단면의 세장한 Euler–Bernoulli 외팔보라면 끝단 집중하중에 대한 처짐 근사는 δ = PL³ / (3EI), I = bh³ / 12입니다. 전단 변형을 무시할 수 있는 조건에서 참고하고 FEM의 변형·경계조건 가정도 맞춥니다.

  3. 설계 변수를 점차 늘리기

    하중 배율만 바뀌는 선형 문제는 기존 해의 선형 비례·중첩으로도 쉽게 계산할 수 있습니다. 파이프라인 확인 후 길이·단면·두께 등 실제 설계 변수를 추가해 AI 적용의 이점을 평가합니다.

  4. 대표값에서 분포로 확장하기

    먼저 최대 변위의 회귀 모델과 비교한 뒤, 필요하면 메시 기반의 변위 분포 예측으로 확장합니다. 응력은 별도 정답 필드로 학습하거나 재료식·미분을 통해 계산할 수 있지만, 변위 오차가 작아도 응력 오차는 커질 수 있습니다.

필요한 데이터 수는 형상 범위·비선형성·목표 오차에 따라 달라집니다. 작은 데이터로 학습곡선을 확인하고 부족한 조건을 추가합니다. 고정단 모서리·집중하중점처럼 특이성이 생기는 위치의 단일 최대 응력만으로 성능을 판단하지 않습니다.

06 · VALIDATION

오차와 물리를 함께 확인하기

학습 손실이 작다는 사실만으로 구조해석의 정확도가 확인되지는 않습니다. 아래는 이 문서에서 제안하는 검토 항목입니다. 오차 허용값은 적용 목적과 기준 해석의 정확도에 맞춰 먼저 정합니다.

구조해석 대리모델 검증 항목
항목확인할 내용
변위변위장의 상대 L2 오차와 주요 위치의 절대 오차. 메시 밀도가 다르면 적절한 공간 가중치도 고려합니다.
응력·변형률성분·평가 위치·평균화 방식을 통일하고, 관심 부위와 응력 집중 영역을 별도로 비교합니다.
힘·에너지구속 반력과 외력의 평형, 경계조건 만족, 변형 에너지 등 물리적 일관성을 확인합니다.
과도응답한 시간 단계뿐 아니라 전체 예측 이력의 오차 누적, 속도·가속도, 접촉·변형의 일관성을 확인합니다.
새로운 조건학습하지 않은 형상·재료·하중 조합을 따로 평가합니다. 입력 범위를 벗어난 사례는 추가 기준 해석으로 확인합니다.
속도와 비용데이터 생성·전처리·학습·추론 시간을 구분하고 같은 장비·조건에서 비교합니다. 추론 속도만으로 전체 비용 절감을 단정하지 않습니다.

공식 충돌 자료도 FEM의 변형 및 주요 지점의 시간 이력을 기준으로 평가합니다. 일반적인 모델 평가 절차는 공식 평가 가이드를 참고하세요. [4] [10]

적용 전에 짚어볼 한계

  • 학습 범위 밖의 형상이나 새로운 메시 연결을 자동으로 잘 처리한다고 가정할 수 없습니다.
  • 접촉·좌굴·파손·소성의 전이가 있는 문제는 별도 상태와 충분한 데이터, 적절한 평가가 필요합니다.
  • PINN도 표본점의 배치·정규화·손실 가중치·최적화에 영향을 받습니다. 물리 잔차가 작아도 관심 응답은 독립적으로 검증해야 합니다.
  • 학습에 사용한 기준 해석의 오차와 가정을 함께 점검해야 합니다. 대리모델이 기준 데이터보다 자동으로 정확해지는 것은 아닙니다.
07 · GETTING STARTED

시작할 때 준비할 것

  • 문제 정의: 예측할 응답과 설계 변수 범위, 허용 오차를 한 장으로 정리합니다.
  • 실행 환경: Python·PyTorch 및 해당 모델의 의존성을 확인합니다. 큰 메시의 학습에는 NVIDIA GPU 기반 구성이 권장되며, 필요한 메모리는 메시·모델·배치 크기에 따라 달라집니다. [8]
  • 버전 맞추기: 본체·예제·의존성의 버전이나 커밋을 고정합니다. 최신 설치 안내와 구버전 예제 코드를 섞지 않습니다. [9]
  • 물리 손실이 필요할 때: 현재 문서의 physicsnemo.sym과 PDE 정의 방식을 확인합니다. 공식 설치 예시는 nvidia-physicsnemo[sym] 선택 기능을 사용합니다. [7]
  • 작은 실험부터: 데이터 읽기 → 한 케이스 학습 → 별도 케이스 예측 → 결과 비교 순서로 확인한 뒤 모델과 데이터 규모를 늘립니다.

이 페이지는 소개·적용 자료입니다. PhysicsNeMo 학습은 별도의 Python 실행 환경에서 진행하며, 여기서 자료를 읽는 것만으로 모바일에서 학습이 실행되지는 않습니다.
