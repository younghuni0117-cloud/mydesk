# 커리어 · 경력직 공고

공개 글 목록: https://younghuni0117-cloud.github.io/mydesk/blog.html?menu=experienced-jobs

기존 `site_navigation`의 다른 메뉴를 보존하고 `career`(커리어) → `experienced-jobs`(경력직 공고)를 추가했습니다. 기존 블로그 목록·상세·편집 기능을 그대로 사용합니다. 글의 `category`는 기존 저장 스키마에 맞춰 `structural`, `menu_id`는 `experienced-jobs`, `topic`은 `경력직 공고`입니다.

조사 기준은 국내 구조·충돌·낙하·진동·내구/피로 Simulation, CAE/FEM 경력직입니다. 대기업·주요 그룹과 중견기업, 책임·수석급 또는 10년 이상 경력을 우선하고 LS-DYNA·HyperMesh·Ansys Workbench·Abaqus·OptiStruct 관련성을 평가합니다. LG 계열사도 다른 기업과 동일하게 추천합니다. 기업 공식 원문을 우선하고 채용 플랫폼으로 보완합니다. 접수 확인 여부, 근무지, 요구 경력, 주요 업무, 도구, 마감일, 원문 URL, 신규/기존/변경/마감 구분을 남깁니다. 근거 없는 지원 가능 판단이나 개인정보 공개는 하지 않습니다.

ChatGPT 자동 작업 한 개가 한국시간 오전 8시/오후 3시 전후(시간대별 유동 실행)로 조사하고 블로그에 직접 게시합니다. 기존 별도 취업정보·콘서트 자동화는 변경하지 않습니다. 같은 날짜/시간대 재시도는 `career-jobs-YYYYMMDD-am` 또는 `career-jobs-YYYYMMDD-pm` 한 글로 갱신하고, 이전 날짜/시간대 글은 보존합니다. 새로운 공고가 없어도 확인 범위와 기존 모집·마감 상태를 정리합니다. 검색이나 원문 확인 실패 시 최신 확인으로 위장하지 않습니다.

게시에는 연결된 Supabase의 `execute_sql`을 사용하며, 관리 비밀번호나 관리키를 저장하지 않습니다. 사이트의 일반 독자·수정·삭제 권한은 그대로 유지합니다. 글 저장 전후 ID·메뉴·내용·등록 시각을 확인하고, 기존 글·달력·로봇 데이터에는 쓰지 않습니다. 자동화가 연결 오류나 게시 실패를 반환하면 성공으로 알리지 않습니다.
