# 마인드맵 편집기 v2

- `mindmap.html`, `mindmap.css`, `mindmap.js`: 독립 페이지. 상단 사이트 헤더와 기존 추가/연결/되돌리기 도구 모음을 제거하고 화면 전체를 작업 공간으로 사용한다. 맵 선택/생성/삭제만 작은 오버레이로 표시한다.
- 모든 화면 크기에서 사이드바는 기본적으로 닫힌 서랍이다. `shell.js` 변경은 `data-page=mindmap`에만 적용한다.
- 박스를 누르면 박스 안에서 직접 글을 편집한다. 박스 가장자리 또는 편집 중이 아닌 박스를 끌어 이동한다. 빈 영역은 화면 이동, 두 손가락은 중심점을 유지하며 확대/축소한다. 휠과 확대 버튼도 유지한다.
- 박스 길게 누르기(550ms), 마우스 오른쪽 버튼, Shift+F10으로 설정을 연다. 글 편집, 하위 박스 추가, 연결/해제, 색상, 삭제, 새 박스, 되돌리기를 제공한다. 빈 공간 길게 누르기도 새 박스 추가를 제공한다. 방향키 이동과 Enter 편집을 지원한다.
- 선택 박스의 상세 글과 맵 제목은 페이지 하단에 배치한다. 상세 글 초안은 선택/맵 전환 시 메모리에 유지하며 저장 버튼으로 모든 상세 글 초안을 저장한다. 저장하지 않은 상세 글은 새로고침 시 복원되지 않는다. 박스 글/위치/연결/맵 제목은 자동 저장한다.
- 새 localStorage 키는 `mydesk.mindmap.v2`. 여러 맵과 activeId를 보존한다. v2가 없으면 기존 `mydesk.mindmap.v1` 내용을 복사하여 이관하며 원래 키는 수정하지 않는다. 잘못된 저장본은 덮어쓰지 않고 저장 중단을 표시한다. 다른 앱의 저장소에는 접근하지 않는다. 기기 간 공유는 이번 범위에 포함되지 않는다.
- 맵 삭제 전 확인한다. 마지막 맵을 삭제하면 새 빈 기본 맵을 생성한다. 일반 삭제는 해당 맵만 삭제하며 원래 v1 보관본은 유지한다.

검증: `NODE_PATH=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules node scripts/verify-mindmap.cjs`

실제 Chromium에서 기존 데이터 이관과 원본 보존, 마우스 드래그, 직접 글쓰기와 HTML 텍스트 안전성, 상세 글 재접속, 여러 맵, 삭제 확인 취소/승인, 두 손가락 확대, 터치 길게 누르기, 삭제 되돌리기, 320/390/768/960/1440 너비, 가로 화면 메뉴 접힘, 다른 앱 저장 보존을 검증한다. 공용 DB 요청은 합성 읽기 응답으로 대체하며 실제 가족 일정은 읽거나 쓰지 않는다.
