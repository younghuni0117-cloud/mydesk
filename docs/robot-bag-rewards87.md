# 샌드백 타격 보상

펀치·발차기 샌드백 훈련의 유효 타격에 `8 + 2×기존 피해량 + 충격 보너스`를 지급한다. 충격 보너스는 전달 충격량과 충돌 접근 속도에 따라 포화하며 최대 22점이다. 기존 피해량 상한 30과 합쳐 타격당 보상 상한은 90점이다. 허공에서 손발을 빠르게 움직이는 것에는 타격 가점이 없다. 상대 로봇 격투·방어의 피해 및 승패 계산은 유지한다.

한 손/발의 모든 충돌 fixture 접촉을 묶어 한 번만 보상한다. 접촉을 완전히 끝내고 0.08초 이상 분리된 뒤 다시 충돌해야 새 타격을 인정하며 기존 최소 타격 간격 0.25초도 유지한다. 접근 속도 1.2m/s 이상과 충격량 0.15N·s 초과 조건은 유지한다. 손은 합쳐진 아래팔 rigid body의 실제 손 쪽 접촉만 인정하고, 발은 발 body 접촉만 인정한다. 몸통으로 부딪치는 경우나 지정하지 않은 공격 유형에 큰 보상을 주지 않는다.

최근 타격 후 1.5초 안에 실제 발 지지·몸통 비접촉·직립 상태를 0.3초 연속 유지하면 한 번만 3점을 준다. 이후 이전 타격부터 3초 안에 새 유효 타격을 하면 2점이 추가된다. 특정 관절 자세나 공격 순서를 스크립트로 지정하지 않는다. 펀치·발차기의 넘어짐은 −100점, 다운 중에는 초당 −4점이다. 최대 단일 타격과 회복·재공격 보너스를 합쳐도 한 번의 넘어짐 비용보다 작다.

새 보상은 `combatVersion:4` 환경으로 구분한다. 모델/정책/보상 파일 포맷 버전은 유지하므로 기존 가중치·ID·학습 횟수·기록은 보존된다. 이전 기준으로 계산한 PPO 경험 버퍼와 검증 점수는 새 훈련에 섞지 않고 재평가한다. 도움말도 실제 계산식에 맞춰 갱신한다.

검증: 실제 손/발 충돌·충격 전달, 분리 후 재타격, 접촉 유지/다중 fixture/접촉 진동 중복 차단, 잘못된 공격 유형/몸통 충돌, 보상 상한과 넘어짐 비용, 회복/재공격 1회 보상, 이전 모델 보존을 테스트했다. 기존 PPO·격투·방어·샌드백 로프·관찰 worker 테스트와 브라우저의 표적/무게/재접속 모델 유지도 확인한다. 새 기준에서 평균 보상이 커지는 것과 실제 공격 능력이 향상되는 것은 구분해서 평가해야 한다.
