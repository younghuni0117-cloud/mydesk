# 기본 운동으로 정리 (update88)

- 활성 과제는 `balance`, `recover`, `walk` 세 가지입니다. 선택·균등 순환·무작위 혼합 학습과 검증이 모두 같은 세 과제만 사용합니다.
- 펀치·발차기·방어·격투, 샌드백, 상대 캐릭터, 경기 HUD와 체력/카운트, 경기 설정과 격투 명령을 제거했습니다. 옛 `fight` 명령은 정지 목표로, 옛 격투 과제 선택은 균형 잡기로 정규화합니다.
- 과거 격투 구현과 전용 검증/초기화 스크립트는 `archive/robot-combat`, `tests/legacy-robot-combat`, `scripts/legacy-robot-combat`의 `.txt` 자료로 보존하며 실행하거나 네트워크에서 불러오지 않습니다.
- 기존 신체 질량, 중력, PD 목표 각도·속도·추가 토크 제어, 회복 보조력, 훈련소와 센서는 유지합니다.

## 모델 호환성

`skillsVersion: 3`으로 이전 모델을 복제·정리합니다. 기본 운동의 가중치/최적화 상태·성과·학습 횟수를 유지하고, 격투 능력/환경/대전 상대 보관함과 해당 PPO 경험은 제거합니다. 삭제된 과제의 과거 시도 횟수는 전체 횟수 정합성을 위한 비활성 회계 정보로만 남습니다. 과제와 상대 관측이 차지했던 입력은 0으로 예약해 기본 운동 입력 위치가 달라지지 않도록 했습니다. 141개 입력, 36개 출력, 4,524개 가중치와 v10 저장 구조/제어 식별자는 서버·기본 운동 가중치 호환성을 위해 유지합니다. 달력·블로그·메뉴 데이터와 저장 서버 스키마는 변경하지 않습니다.

## 새 캐릭터

`trainee` / **트레이닝 파트너**를 상세 옵션의 기존 캐릭터 목록에 하나 추가했습니다. 짧은 머리, 청록색 운동복, 어두운 운동 바지와 밝은 운동화의 직접 그린 측면 캐릭터입니다. 기존 캐릭터 여섯 개는 유지하며 외형에 따른 질량·관절·제어 차이는 없습니다. 선택은 기존 `mydesk.robot.skin` 키에 기기별 저장됩니다.
