# LLM 성장시키기

My Desk의 **LLM 만들기 → LLM 성장시키기**에서 한국어 샘플이나 사용자 문서로 웹브라우저에서 학습할 수 있습니다. 학습, 검증, 추론은 CPU Web Worker에서 실행합니다. 별도의 설치나 빌드 단계가 없습니다.

## 학습과 평가

기본 모델은 은닉 차원 24, 헤드 3개, 레이어 1개, 최대 문맥 16입니다. 문자와 학습 가능한 위치 임베딩, Pre-LN, 인과적 멀티헤드 어텐션, 잔차 연결, ReLU FFN, 최종 정규화와 어휘 투영을 사용합니다. Float32 행렬과 연산별 역전파 및 수치적으로 안정적인 교차 엔트로피를 사용합니다. Adam의 두 모멘트와 기울기 클리핑을 적용합니다.

학습은 무작위로 문장과 연속 창을 뽑아 한 Step씩 갱신합니다. 검증은 첫 Step과 이후 10 Step 간격으로 고정 창에서 계산합니다. 큰 검증 분할은 결정적으로 최대 24개 창을 평가합니다. 별도로 예약한 고정 평가 문장도 동일한 방식으로 평가합니다. 학습 어휘에 없는 검증 문자는 UNK로 계산하며 그 개수를 화면에 표시합니다. 동일 문장의 학습·검증 배정은 데이터 버전 변경 후에도 유지합니다.

TXT와 DOCX 본문, 텍스트 PDF 및 직접 입력을 지원합니다. PDF는 판독 가능한 텍스트를 로컬에서 추출합니다. 이미지 전용 PDF는 OCR한 뒤 추가할 수 있습니다. 사용자의 문서 원본과 생성 입력은 외부로 보내지 않습니다.

## 저장

IndexedDB는 모델별 체크포인트, 학습 Step 이력 및 생성 결과를 저장합니다. 자동 저장은 100 Step 간격으로 최신 자동 저장을 교체합니다. 생성, 일시정지, 종료 및 수동 저장은 모델의 체크포인트 목록에 보관합니다. 가중치, 모멘트, 문서, 데이터 배정, 난수 상태 및 이력 기록은 한 트랜잭션에서 저장합니다. 다른 탭이 같은 모델의 최신 체크포인트를 이미 바꿨다면 저장을 중단하고 다시 불러오도록 표시합니다. 과거 체크포인트 복원은 새 모델을 만들므로 그 뒤의 학습도 목록에 남습니다.

학습 중에 탭이 숨겨지면 일시정지와 저장을 시도합니다. 브라우저나 운영체제가 즉시 종료하면 마지막으로 완료된 체크포인트에서 복원합니다. 브라우저 데이터 삭제 및 저장 공간 회수에 따라 로컬 자료가 없어질 수 있습니다. 현재 다른 브라우저나 기기와 동기화하는 기능은 없습니다.

## 엔진 연동

화면은 `llm/client.mjs`의 `request(action, args)` 및 `progress`, `saved`, `error` 이벤트를 사용합니다. 원격 엔진은 이 요청·응답 경계를 통해 학습 제어와 지표를 제공할 수 있습니다. 브라우저 체크포인트에는 엔진 및 포맷 버전이 포함됩니다. 추후 PyTorch 연동 시 인증된 중계 서비스에 PC가 연결하고, 엔진별 체크포인트 검증과 변환을 별도로 구현해야 합니다.

## 검증

```sh
node --test tests/llm-engine.test.mjs tests/navigation.test.mjs
python3 -m http.server 3000
# Playwright와 Chromium이 설치된 환경에서 실행
node scripts/verify-llm-lab.cjs
```


## 학습과 글 생성 화면

기본 화면에는 적용된 문서 목록, 추가 학습 횟수, 학습·검증 손실, 진행 횟수, 학습 시간과 저장 상태를 표시합니다. 기본 500회이며 1~100,000회에서 선택합니다. 일시정지 후 다시 시작하면 입력된 횟수만큼 추가 학습합니다. 지정 횟수를 완료하면 자동 저장합니다.

글 선택·추가에서 기본 샘플을 고르거나 문서를 추가한 다음 현재 모델에 적용하거나 새 모델로 사용합니다. 최근 학습 구간을 펼치면 엔진이 실제로 처리한 텍스트를 확인할 수 있습니다.

학습 중에도 글을 생성할 수 있습니다. 생성 시작 시점의 가중치를 복사해 사용하고, 각 토큰의 실제 확률과 선택 결과를 보여 준 뒤 글을 이어 씁니다. 생성 멈추기와 한 토큰 생성도 지원합니다. 현재 모델은 문자 단위이므로 한 번의 선택은 주로 글자 하나입니다.

학습 곡선의 가로축은 0부터 현재까지 전체 이력을 표시합니다. 최근 같은 데이터 버전의 검증 시점 6개를 두 묶음으로 평균해 손실 추세를 안내합니다. 과적합·과소적합 안내는 추세를 해석하는 참고 정보입니다. 상세 분석을 열면 토큰별 확률과 Attention, 가중치 패널을 사용할 수 있습니다.
