# 맛집 기록

`restaurants.html`은 기존 달력 아래의 독립 메뉴다. 지도 경계는 저장소에 포함되어 외부 지도 타일 없이 표시되며, 기록은 기존 Supabase 프로젝트의 별도 `restaurant_records` 테이블에 저장된다. `sync/restaurant-records.sql`이 테이블·권한·메뉴판 버킷 정의다. 초기 두 식당은 운영 DB에 한 번만 추가했으며 페이지를 열 때 초기화하거나 재등록하지 않는다.

새 기록은 공개 등록할 수 있다. 수정·삭제는 기존 글·메뉴 관리 연결을 사용하며, 기존 관리 비밀번호·권한 구현을 변경하지 않았다. 수정은 읽었던 `revision`과 일치할 때만 저장한다. 새 기록 재시도는 동일 ID·동일 내용인지 확인하고 기존 내용을 덮어쓰지 않는다. 서버 연결 실패 시 입력을 유지하고 저장 성공으로 표시하지 않는다. 목록 캐시는 오프라인 조회 보조용이며 서버 데이터를 대체하거나 자동 업로드하지 않는다.

메뉴판은 `restaurant-menus` 공개 Storage 버킷에 별도 저장한다. 최대 6장, 한 장 8MB, JPEG/PNG/WebP만 허용한다. 작은 파일은 그대로 저장하며 2MB 초과 사진은 최대 긴 변 2400px JPEG로 처리한다. 공개 업로드는 새 UUID 파일만 만들 수 있고 기존 사진 교체·삭제 권한은 없다. 기록에서 첨부를 제거해도 Storage 원본은 보존되며, 물리 정리는 서버 관리 작업으로 분리한다. 업로드 실패 후 재시도에서는 이미 업로드한 경로를 재사용한다.

주소 검색은 사용자가 버튼을 누른 경우에만 Nominatim에 요청한다(자동완성 없음, 연속 요청 제한). 도로 중심점이 반환될 수 있어 결과를 선택하고 위치를 확인하도록 안내한다. 검색 실패 시 지도 직접 선택 또는 좌표 입력으로 등록할 수 있다. 실제 길찾기는 네이버 지도 링크로 연다.

## 지도와 초기 정보 출처

- 지도: [southkorea-maps KOSTAT 2013 단순화 시도 경계](https://github.com/southkorea/southkorea-maps/blob/master/kostat/2013/json/skorea_provinces_geo_simple.json). 해당 저장소 README는 KOSTAT 자료에 공유·수정 가능을 명시한다. 표시용 좌표를 소수점 두 자리 SVG 경로로 변환했으며 최신 행정경계 안내나 정밀 길찾기 용도가 아니다.
- 주소 검색: [OpenStreetMap/Nominatim](https://www.openstreetmap.org/copyright).
- 정원칼국수: [관광 안내](https://www.ktriptips.com/kor/food/2749005)의 의왕 능안길 146, 지도 좌표와 대표 메뉴. 동명 식당의 계원대학로 주소와 혼용하지 않았다.
- 화목칼국수 포천아트밸리점: [포천아트밸리 공식 주변 안내](https://artvalley.pcfac.or.kr/sub07/sub02.html?cate=Korean+food)의 아트밸리로 189-2 나동 1층. 위치는 주소 지도 기준이며 근사 위치임을 기록에 안내했다.
- 방문 후기·방문 날짜·메뉴판 사진·현재 가격은 임의 생성하지 않았다.

`NODE_PATH=… node scripts/verify-restaurants.cjs` (localhost:8004 미리보기 서버 필요)

브라우저 테스트는 별도 메모리 저장소로 등록·사진 실패/재시도·확대·관리 수정/삭제·화면 크기 4종을 확인한다. 운영 저장소의 실제 업로드·공개 이미지 조회·등록은 임시 ID로 별도 확인했고 임시 파일·행·검증 권한은 제거했다. 기존 블로그·달력·로봇 테이블은 변경하지 않는다.

## 시·도 확대 지도

전국 지도에서 시·도 경계를 누르거나 ‘지역 확대’ 목록을 선택하면 **같은 지도 캔버스 안에서** 선택한 지역을 향해 약 0.82초 동안 부드럽게 이동·확대한다. 주변 지역은 사라지고 해당 지역의 시·군·구 경계와 지명이 나타난다. 별도 창·배경 가림·페이지 스크롤 잠금은 없다. ‘전국 지도’ 또는 지도 안 ‘← 전국’을 누르면 이전 전국 지도 위치·확대 수준으로 역방향 전환한다.

시·군·구 경계와 지명은 KOSTAT 2013 `skorea_municipalities_geo_simple.json`을 변환한 `assets/korea-food-districts.json`이다. 세부 자료는 한 번만 읽고 재사용한다. 전국 지도에는 작은 깃발과 지도 밖 정보 카드만 표시하고, 지역 확대 상태에는 깃발 옆에 식당 이름을 표시한다. 이름을 누르면 아래 기존 식당 기록이 펼쳐진다. 지역 식당은 실제 좌표와 시·도 경계로 분류한다(구멍 영역 포함).

카메라는 중심 좌표와 배율을 보간하며, 배율은 로그 공간에서 변화해 큰 확대도 연속적으로 보인다. 깃발·이름·지명은 매 프레임 같은 카메라 좌표를 사용한다. 지역을 빠르게 바꾸면 이전 프레임 요청을 취소하고 현재 위치에서 새 지역으로 이어서 이동한다. 오래 걸린 이전 지역 데이터가 뒤늦게 덮어쓰지 않도록 세대를 검사한다. 동작 줄이기 설정에서는 모션을 생략한다. 확대 상태는 터치 드래그로 이동할 수 있다.

`NODE_PATH=… node scripts/verify-restaurant-regions.cjs`는 모달이 없는 연속 카메라 프레임, 깃발·이름, 직접 터치, 지역 식당 분리, 경계, 빠른 전환, 축소 복귀·전국 뷰 보존, 동작 줄이기와 4개 화면 크기를 별도 메모리 데이터로 확인한다. 기존 등록·메뉴판 사진·관리 검증은 `verify-restaurants.cjs`로 함께 실행한다.

## 단순 읍·면·동 지도와 블로그 (food5)

전국·시도·시군구의 기존 연한 SVG 지도 스타일을 유지하고, 확대 시 **도로·건물·항공사진 없이 읍·면·동 경계와 이름만** 표시한다. 현재 페이지는 실제 지도 타일로 전환하지 않으며 Leaflet을 불러오지 않는다. 이전 페이지가 캐시된 방문자의 호환성을 위해 기존 파일만 보관한다. 두 손가락 중점을 기준으로 확대·축소하고, 한 손가락 드래그로 이동한다. 최대 배율은 128배이며 지역 선택·전체 지도 복귀·깃발·식당 이름·바깥 정보 카드를 유지한다. 깊이 확대하면 전국 모드에서도 식당 이름을 지도에 표시한다.

읍·면·동 경계는 기존 시도·시군구와 동일한 southkorea-maps KOSTAT 2013 `skorea_submunicipalities_geo_simple.json`이다. **2013년 행정경계**이므로 현재 행정구역과 다를 수 있다. 원본을 `scripts/build-food-neighborhoods.py source.json`으로 투영해 `assets/food-neighborhoods/{province-code}.json` 17개 파일로 분할했다(총 3,482개, 약 0.87MB). 해당 화면에 필요한 시도의 파일만 확대 시 읽고 재사용한다. 화면 밖 경계와 겹치는 이름은 표시하지 않는다. 지도 출처와 자료 연도는 하단에 표시한다.

등록창의 선택 항목 `blog_url`은 HTTPS URL만 허용하고 인증정보가 들어간 URL·실행 가능한 스킴은 거부한다. 기존 `source_url`(기본 정보 출처)은 변경하지 않는다. `sync/restaurant-blog-url.sql`은 기존 테이블에 빈 문자열 기본값의 컬럼만 추가하고 기존 관리 정책 아래 해당 컬럼 수정 권한만 추가한다. 기존 행·사진·수정 시각·revision·관리 연결은 유지한다. 공개 신규 등록과 관리 연결 후 수정 권한은 기존과 같다. 초기 스키마를 새로 만드는 환경에서는 `restaurant-records.sql` 다음에 적용한다.

식당 기록의 주소 또는 블로그 주소를 누르면 페이지 안의 모달 iframe으로 원문을 연다. 원문은 복제·가공하거나 서버를 통해 우회하지 않는다. 외부 블로그의 CSP/X-Frame-Options가 삽입을 차단하면 표시할 수 없으므로 팝업의 ‘원문 보기’로 새 창을 연다. 닫기·Escape 시 iframe을 제거해 미디어와 연결을 정리한다. 링크·식당명은 DOM 텍스트/HTML escaping을 적용하고 iframe에는 sandbox와 no-referrer를 적용한다.

검증: `node --test tests/restaurant-data.test.mjs tests/navigation.test.mjs`의 URL 검증·저장·기존 주소/사진 테스트, `verify-restaurants.cjs`의 등록·사진·관리, `verify-restaurant-regions.cjs`의 지역 전환·복귀·동작 줄이기 회귀, `verify-restaurant-touch.cjs`의 실제 두 손가락 확대/축소·이동·동 경계/이름·외부 타일 요청 없음·블로그 등록/재접속·팝업·삽입 제한 안내·5개 화면 크기. 운영 기록을 변경하지 않는 모의 응답으로 수행한다.

HTML과 컨트롤러의 food5 버전이 맞지 않으면 저장소를 건드리지 않고 캐시 우회 주소로 한 번 갱신한다. 오래된 폼에 새 필드를 연결하다 오류가 나는 것을 방지한다.
