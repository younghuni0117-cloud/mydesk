학습 설정

선택한 미션의 초기 조건에서 연속 토크를 학습하고, 별도 난이도 평가를 통과하면 초기 각도 범위를 확대합니다. 화면은 최근 정책의 별도 실시간 물리 관찰입니다. 보상 증가만으로 성공하지 않으며 미션별 고정 12조건과 추가 12조건을 모두 통과하면 달성 기록과 성공 정책을 보존하며 학습은 계속할 수 있습니다.

PPO 완료 업데이트마다 현재 정책·가치망·Adam·난수 상태를 IndexedDB에 저장합니다. 이전 정상 저장본과 최고·성공 정책도 별도로 유지합니다.

초기 조건

수동 실험

선택 시 초기 자세만 바뀝니다. 동작이나 제어 정책을 자동으로 넣지 않습니다.

7개 자유 강체와 6개 내부 관절입니다. 골반은 지면에 고정되지 않습니다. 크기 1배에서 다리 길이 약 0.84m, 전체 질량 19.6kg이며 크기·질량 배율로 조정합니다. +토크는 관절 B를 반시계로, A를 반대로 회전시킵니다. 수동 밀기는 관찰 장면에만 적용되며, 학습 시도에는 별도의 랜덤 외력이 들어갑니다. 고정 검증 외력은 ±1.2 N·s이며 화면 밀기 3 N·s와 강도가 다릅니다.

서 있기 보상: 골반 높이×직립도, 골반 기울기·속도·질량중심 이탈·토크 비용, 넘어짐 감점입니다. 성공은 두 평가군에 기록하고 계속 학습합니다. 걷기·넘어졌다 일어나기·상체·팔은 다음 단계입니다.
