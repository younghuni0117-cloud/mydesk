# Supabase 자동 동기화 연결

현재 프로젝트 URL과 공개 키는 비어 있으며 자동 동기화는 비활성입니다. 계정 연결이 도구에 전달되면 새 프로젝트 `mydesk-robot-sync`를 만들고 다음 설정을 적용합니다. 기존 GitHub Pages 주소를 그대로 사용합니다.

1. 새 프로젝트에 `schema.sql`을 실행합니다. `robot_models`의 RLS는 인증된 사용자가 자신의 `user_id` 행만 조회·등록·수정하도록 제한합니다.
2. Auth의 Site URL과 허용 Redirect URL에 `https://younghuni0117-cloud.github.io/mydesk/robot.html`을 등록하고 이메일 로그인을 활성화합니다. 실제 이메일 링크 발송·수신도 확인합니다.
3. `robot-sync-config.mjs`의 `url`과 `publishableKey`에 프로젝트 URL 및 **공개 publishable/anon 키만** 넣습니다. service_role, secret 키, DB 비밀번호는 웹사이트나 저장소에 넣지 않습니다.
4. 두 기기에서 같은 이메일 계정으로 로그인합니다. 모델·시도 횟수·학습 분포를 10초 지연 저장하고 15초마다 다른 기기의 갱신을 확인합니다. 학습 종료 시 즉시 저장을 시도합니다.
5. 서로 다른 두 사용자로 RLS 격리를 확인하고, 같은 사용자 두 기기로 저장·재접속·충돌 선택을 확인합니다. 실제 서버 검증 전 자동 공유가 작동한다고 안내하지 않습니다.

동시에 두 기기에서 학습하면 서버 `revision`을 조건으로 수정합니다. 서버가 먼저 변경됐다면 덮어쓰지 않고 선택을 요구합니다. 파라미터를 산술 평균하거나 학습 횟수를 더해 가짜 통합 모델을 만들지 않습니다. 기기 원본은 로컬 백업에 유지되며 선택 전에 파일로 내보낼 수 있습니다.

로그인 토큰은 브라우저에 저장하고 다른 사용자로 전환할 때 계정별 모델 백업을 분리합니다. 오프라인에서는 로컬 상태를 유지하고 연결이 복구되면 재시도합니다. 브라우저 저장을 지우면 아직 서버로 전송되지 않은 변경은 사라질 수 있습니다. 모바일에서 창이 닫히기 직전의 서버 저장은 보장하지 않습니다.

클라이언트 검증: `node --test tests/robot-sync.test.mjs`. 이 검증은 실제 Supabase RLS·이메일 설정 검증을 대체하지 않습니다.
