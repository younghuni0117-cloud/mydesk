# 로그인 없는 공용 로봇 모델

기존 `mydesk-robot-sync` 서버를 재사용합니다. 방문자 가입·로그인·이메일·토큰 입력은 없습니다. 브라우저에는 공개용 publishable key만 포함하며, GitHub 토큰이나 service-role key는 사용하지 않습니다.

현재 스키마는 `public-model.sql`입니다. `public.robot_shared_model`의 `main` 행 하나에 모델·가중치·CEM/PPO 상태·횟수·그래프를 저장합니다. RLS는 익명/인증 역할에 이 한 행의 SELECT/INSERT/UPDATE만 허용하고 DELETE는 허용하지 않습니다. 데이터 공개와 덮어쓰기는 사용자가 명시적으로 선택한 동작입니다. 기존 로그인 전용 `robot_models` 테이블의 접근 권한은 바꾸지 않았습니다.

서버가 비었을 때만 기존 학습 기록으로 첫 모델을 등록하고, 등록 경합은 `ignore-duplicates`로 첫 등록을 유지합니다. 학습이 없는 방문은 0회 모델을 등록하지 않습니다. 이후 실제 학습 저장은 `merge-duplicates`로 마지막 쓰기가 이깁니다. 서버 트리거가 변경 번호와 시각을 정합니다. 더 높은 횟수나 더 좋은 모델만 허용하는 조건은 없습니다.

학습 중 완료된 스냅샷을 최대 30초 간격으로 올리고 종료/중지 때 최종 저장을 기다립니다. 학습하지 않을 때에는 15초마다 변경 번호를 확인하며, 변경된 경우 전체 모델을 읽습니다. 학습 시작 전과 화면 복귀 때도 확인합니다. 학습 중에는 다른 기기의 결과로 현재 학습을 중단하지 않습니다. 두 기기의 결과를 합치지 않습니다.

로컬 `mydesk.robot.v5`는 최신 작업 상태 한 개의 캐시입니다. 연결 실패 시 미전송 표시를 저장하고 재연결 시 자동 재시도합니다. 새 백업·원본·복원 이력 또는 IndexedDB 사본을 만들지 않습니다. 구버전의 과거 로컬 기록은 별도로 삭제하지 않지만 새 페이지는 과거 백업을 읽거나 복원하지 않습니다. 화면 설정은 기기별입니다. 초기화는 확인 후 공용 모델 전체를 0회 모델로 덮어씁니다.

검증: `node --test tests/robot-shared-storage.test.mjs tests/robot-ui.test.mjs`와 `node scripts/verify-robot-sharing.cjs`. 브라우저 다중 기기 검사는 모델 API를 모두 가로채 격리된 저장소에서 실행하므로 실제 서버에 쓰지 않습니다. 실제 서버에서는 공개 키를 통한 브라우저 읽기·초기 등록과, ROLLBACK하는 익명 역할 트랜잭션에서 INSERT/UPDATE·변경 번호 증가를 검사했습니다. 보안 advisors의 경고는 0개였습니다.

`schema.sql`은 폐기된 로그인 방식의 과거 설정 기록이며 현재 공유 방식에 사용하지 않습니다.

robot34의 지형 센서 모델은 1,192개 가중치를 사용합니다. 저장 제약은 기존 880개와 새 1,192개 형식을 모두 허용하며 버전 5·8MiB 한도·RLS·권한은 유지합니다. 서버의 `allow_terrain_sensor_robot_policy` 이관은 CHECK 제약만 변경하고 기존 모델 행을 쓰거나 지우지 않습니다. 검증은 실제 CHECK 표현식을 880/1192/881 크기의 가짜 JSON에 평가해 두 지원 형식만 허용하는지 확인했고, 작업 전후 공용 모델의 변경 번호·학습 횟수·전체 내용 지문이 동일함을 확인했습니다.
