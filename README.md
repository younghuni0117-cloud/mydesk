# My Desk

정보와 자료, 배움의 기록을 모으는 개인 홈페이지입니다. 왼쪽 메뉴에서 홈, 정보·자료, 미로 탐험, 카트폴, 2D 로봇을 선택합니다. 각 콘텐츠는 독립된 HTML 페이지이며, 홈에서는 게임이 실행되지 않습니다. 모바일에서는 메뉴 버튼으로 사이드바를 여닫을 수 있습니다.

**홈페이지:** https://younghuni0117-cloud.github.io/mydesk/

## GitHub에서 수정하기

이 저장소의 `main` 브랜치에서 파일을 열고 연필(Edit) 버튼으로 수정한 뒤 Commit changes를 누르세요. GitHub Pages가 `main` 브랜치의 루트(`/`)에서 자동으로 다시 배포합니다. 진행 상황은 저장소 Actions 탭에서 확인할 수 있습니다.

자료를 추가하려면 `resources.html`에 내용을 넣고 필요에 따라 `index.html`에서 링크하세요. 새 페이지를 추가할 때 왼쪽 메뉴도 바꾸려면 각 HTML 파일의 `sidebar` 내 링크를 함께 수정합니다. 기존 공유 주소의 `#experiments`, `#cartpole`, `#how`는 새 게임 페이지로 연결됩니다.

## 로컬 실행

설치·빌드 없이 정적 서버로 실행합니다. 카트폴은 ES 모듈을 사용하므로 파일을 직접 열기보다 아래 명령을 사용하세요.

```sh
python3 -m http.server 8000
```

http://localhost:8000 에 접속합니다. Google Fonts를 불러올 수 없으면 기본 글꼴을 사용합니다.

## 강화학습 체험

미로는 탐험 비율과 속도를 조절하며 AI를 학습하거나 직접 이동할 수 있습니다. 학습 내용은 페이지를 벗어나면 초기화됩니다.

카트폴은 방향키와 터치로 직접 플레이하거나, 선택한 난이도의 AI를 학습한 뒤 보존 모델로 실행할 수 있습니다. 학습 시도 횟수(1~10,000회)를 직접 입력하며, 게임 시작부터 실패 또는 20초 성공까지가 1회입니다. 입력한 횟수를 정확히 수행하고, 실행은 자동으로 시작하지 않습니다. **학습 모델 실행**을 누르면 해당 난이도에서 가장 높은 고정 평가 평균 누적 보상을 얻은 모델의 가중치를 복사해 사용합니다. 실행 중 가중치는 바뀌지 않습니다.

### 난이도

| 난이도 | 물리·종료 조건 |
| --- | --- |
| 쉬움 | 긴 1단 막대, ±20° 허용 |
| 기본 | 기존 1단 막대, ±12° 허용 |
| 어려움 | 짧은 막대·높은 중력, ±10° 허용 |
| 2단 관절 | 두 막대를 직렬로 연결, 각 막대 ±20° 허용 |

모든 난이도에서 카트가 ±2.4m를 벗어나면 종료합니다. 1,000스텝(20초)을 버티면 성공입니다. 실패한 시점에 시간과 점수를 확정한 뒤, 제어 입력 없이 막대가 바닥에 닿아 튕기고 가라앉는 모션을 보여줍니다. 이 종료 모션은 학습 시도·생존 시간·보상에 추가되지 않습니다. 모션을 일시정지하거나 이어 볼 수 있습니다. 2단 관절은 두 균일 막대의 연성 질량 행렬을 풀고 두 번의 중점 적분으로 움직임을 계산합니다. 위·아래 막대의 각도와 각속도는 독립 상태입니다.

### 학습·그래프·저장

CEM(Cross-Entropy Method)으로 1단은 4개 가중치, 2단은 6개 가중치를 학습합니다. 1단은 묶음별 25개 후보·상위 6개, 2단은 49개 후보·상위 8개로 분포를 갱신합니다. 각 후보는 동일한 3개 학습 시작 조건을 시도합니다. 이후 각 묶음 후보를 **난이도별 고정된 8개 시작 조건**으로 평가합니다. 학습은 게임 시도 3회마다 브라우저에 제어를 넘겨 중지·난이도 전환이 가능하며, 완료한 시도는 즉시 횟수에 포함됩니다. 요청 횟수 도달 또는 중지 시 현재까지의 후보를 별도로 평가해 최고 모델을 보존합니다. 미완료 후보·평가 순서·부분 점수를 저장해 다음 요청에서 정확히 이어갑니다.

오른쪽 그래프의 회색 점선은 평가 시점별 후보의 평균 누적 보상, 파란 실선은 보존된 최고 모델의 평균 누적 보상입니다. 20초 성공률도 이 8회 평가 기준이며, 매 실행의 무작위 시작 조건에서 똑같은 결과를 보장하지 않습니다. 가로축은 누적 학습 시도 횟수입니다. 성능 확인을 위한 별도 8회 평가는 입력한 학습 시도 수에 포함하지 않습니다. 그래프에는 최근 120개 평가 기록을 표시합니다. 미리 훈련된 가중치나 정답 제어기는 사용하지 않습니다.

난이도별로 모델·학습 분포·진행 중인 후보 평가·그래프·내 최고 기록을 `mydesk.cartpole.v3.<difficulty>` localStorage에 나누어 저장합니다. 기존 v1/v2 모델 가중치·누적 시도·내 최고 기록은 불러와 유지하고, 새 보상 규칙으로 다시 평가합니다. 과거 시간 그래프를 점수로 변환하지 않으며, 새 보상 그래프는 이관 시점의 누적 시도에서 시작합니다. 점수 단위가 다른 미완료 v2 후보 평가는 이관하지 않고, 원본 저장 키는 보존합니다. 초기화 버튼은 현재 난이도의 AI 학습만 지우고, 내 최고 기록과 다른 난이도의 모델은 유지합니다.

### 상벌점 규칙

- 유효한 스텝(0.02초)마다 기본 +1점
- 자세 감점: −0.2 × 각 막대의 `(각도/허용 각도)²` 평균
- 위치 감점: −0.05 × `(카트 위치/2.4)²`
- 제어 감점: −0.01 × `입력 힘²`
- 실패 순간 −100점, 20초 성공 시 +100점

그래프·후보 순위·보존 모델 선택에 같은 실제 누적 보상을 사용합니다. 보상 범위는 −100~+1,100점이며 0점 기준선을 표시합니다. 실패 후 충돌 모션은 보상에 영향을 주지 않습니다.

바닥 충돌은 질량 행렬을 통한 수직 충격량, 반발계수 0.38, 접선 마찰과 위치 보정을 적용합니다. 마찰이 수직 반발을 지우지 않도록 제약 공간에 투영합니다. 1단·2단 모두 전체 막대가 카메라에 들어오도록 시야를 조절합니다.

검증: `node --test tests/cartpole.test.mjs tests/cartpole-motion.test.mjs`

기존 Sites 사이트는 별도 배포이며, 이 저장소의 변경은 GitHub Pages 주소에 반영됩니다.

## 모바일·폴더블 게임 화면

두 게임은 기기 이름 대신 실제 가용 화면 크기로 배치합니다. 좁은 화면(너비 600px 미만)은 게임판 위·조작부 아래, 넓은 화면은 게임판과 조작부를 나란히 배치합니다. 회전한 외부 화면은 너비 540px 이상·높이 540px 미만일 때 가로 배치를 사용합니다. 게임 페이지에서는 내부 화면에서도 왼쪽 메뉴를 접어 게임 공간을 확보합니다.

화면 높이는 `visualViewport`와 동적 뷰포트에 맞추며, 접기·펼치기·회전·브라우저 주소창 크기 변화에 따라 다시 계산합니다. 도움말은 별도 대화상자에서 읽고, 지원 브라우저에서는 전체 화면 버튼을 사용할 수 있습니다. 게임 진행 화면에는 모드, 기록, 설정, 핵심 조작을 유지합니다. 도움말을 열면 진행·학습을 일시정지합니다.

가용 높이가 지나치게 작거나 브라우저를 확대하면 조작을 잘라내지 않도록 일반 스크롤 배치로 돌아갑니다. 실기기·브라우저 화면 검증은 별도로 필요합니다.

## 로봇 강화학습

### 기본 동작 없는 신경망 정책

자세 유지 PD 제어, 발을 드는 IK, 보행 주기, 회복 단계, 팔·다리의 미리 정한 목표각은 제거했습니다. 47개 물리 상태·목표 입력 → tanh 은닉 12개 → 16개 관절 토크 출력의 신경망을 사용하며 가중치는 784개입니다. 입력은 몸통 방향·각속도, 골반 높이·속도, 목표 이동 속도, 좌우 발 접촉, 앞 지형·장애물 높이, 동굴 천장 여유, 16개 관절 각도·속도, 목표 위치 오차·위치 목표 여부·낮은 자세 여부입니다. 시간에 따른 사인파나 운동 과제별 동작 분기는 없습니다.

새 모델의 모든 가중치는 0이며 능동 관절 토크도 정확히 0입니다. 초기화한 캐릭터는 중력·충돌·마찰 때문에 쓰러지거나 움직일 수 있지만 기본 운동 동작을 수행하지 않습니다. 학습 후보의 무작위 가중치가 센서 상태에 따라 관절 힘을 만들고, 실제 누적 보상으로 CEM 정책 탐색을 진행합니다. 후보 12개 중 상위 4개로 분포를 갱신합니다. 통합 모델 채택 시 다섯 능력을 모두 재검증하고 이전 통과 사례와 보상을 보호합니다. 선택 과제를 먼저 검증하고, 기존 성능 보존 기준을 실패한 후보는 즉시 기각하여 남은 검증을 생략합니다. 채택 후보는 모든 과제와 명령 검증을 통과해야 합니다. 미평가 후보 보상은 추정하지 않고 해당 점선 구간을 비웁니다. 별도의 네 명령 시험 평균 보상도 채택 점수에 포함하며, 표·그래프에는 기존 운동별 검증 보상만 표시합니다. 목표 동작 성공에는 많은 시도가 필요할 수 있으며 성공을 보장하지 않습니다.

### 물리와 보상

17개 강체·16개 관절, 총 질량 19.9kg입니다. 관절 각도·최대 토크·마찰·중력·충돌은 유지합니다. 허리에는 강성 55 N·m/rad와 감쇠 9 N·m·s/rad의 수동 내부 저항만 남습니다. 골반과 몸통에 반대 토크를 적용하며 몸 전체를 세우는 외부 힘은 없습니다. 관절 모터의 목표각·목표 속도 제어는 꺼져 있고 신경망 토크를 직접 적용합니다. 물리적인 관절 한계 부근과 무부하 속도(9rad/s) 부근에서는 출력 토크를 제한합니다. 정책은 20Hz로 힘을 갱신하고 물리는 활동량·관절 속도에 따라 120~480Hz 하위 스텝, 화면은 주사율에 맞춰 보간합니다.

`robot-rewards.mjs`에 공통·과제별 보상 계산과 도움말 설정을 함께 둡니다. 매 프레임의 상점·벌점을 합산하며 에피소드 지표 `rewardTerms`로 항목별 누적값을 확인할 수 있습니다. 서 있기, 속도 일치, 이동·높이 증가·일어서기·장애물 통과는 보상하고 기울기·낮은 골반·넘어짐·충격·에너지 사용·원치 않는 이동은 감점합니다. 일어서기의 처음 누운 상태에는 넘어짐 벌점을 주지 않습니다. 물리 도움말은 선택한 과제의 목표 속도·시도 길이·상점·벌점·검증 통과 기준을 보여주며, 수치는 실제 계산 설정에서 가져옵니다.

### 학습·관찰·조작

균형 잡기·일어서기·걷기·달리기·장애물 통과는 동일한 신경망을 사용합니다. 시도 횟수는 100·200·500·1,000·2,000·5,000·10,000·100,000회 중 선택합니다. 1회는 과제별 8~12초 가상 시간이며 검증과 관찰은 학습 횟수에 포함하지 않습니다. 상세 옵션에서 자동 밀기 체크를 켜면 각 시도에서 무작위 시점·0~360도 방향·위치로 정확히 한 번 밉니다. 세기는 상세 옵션에서 0.1~30 N·s 범위의 최소/최대를 정하고, 기본은 1~6 N·s입니다. 검증의 네 조건은 설정과 별개로 고정합니다.

버튼 순서는 학습 시작 → 중간 관찰 → 통합 모델 실행입니다. 학습 중에는 최근 후보가 실제 시도에서 만든 장면을 보간 재생합니다. 관찰 갱신 시도만 장면을 저장하고 다른 시도는 지표만 계산합니다. 학습과 화면에서 같은 관절 물리를 동시에 계산하지 않습니다. 직접 밀기·통합 모델 실행·학습 종료 후 중간 관찰은 실시간 물리이며 해당 시도의 시드·밀기·목표 변경 계획을 재사용합니다. 통합 모델 실행은 고정된 가중치로 새로 관찰하고 자동으로 밀지 않습니다. 왼쪽 드래그는 직접 밀기, 오른쪽 드래그는 시점 이동, 휠·두 손가락은 확대·이동입니다. 직접 밀기는 학습 데이터에 포함되지 않습니다. 동일 지형에서 학습 시작·중지·재시작·운동 과제 변경은 준비된 학습 스레드를 유지합니다. 학습 시작마다 24개 검증 에피소드를 반복하지 않으며, 채택되지 않은 후보가 있어도 실제 탐색 분포(mean/spread)를 저장해 이어갑니다. 새 지형·모델 불러오기·초기화는 새로 검증합니다. 확인 중 상태와 초 단위 남은 시간을 표시하며, 창이 숨겨지면 학습 중지를 요청합니다.

그래프의 가로축은 선택한 운동 능력의 학습 횟수, 세로축은 그 능력의 실제 평균 보상입니다. 기록은 과제별 누적 횟수도 저장하고 각 능력의 첫 점·최근 점을 남기며 압축합니다. 다른 과제를 훈련해 공통 모델의 보상이 변하면 같은 횟수의 마지막 점을 갱신합니다. 왼쪽 아래 게이지는 이번 학습의 진행과 전체 누적 횟수를 보여줍니다.

### 명령·목표 설정

상세 옵션 바로 위의 접이식 패널은 기본적으로 닫혀 있습니다. 제자리 유지 / 계속 이동 / 목표 위치로 이동, 앞뒤 방향, 0.05~2.5m/s 속도, −30~30m 위치, 자유 / 낮은 자세를 선택합니다. 위치는 로봇 출발점 0m 기준이며 목표 선택 버튼을 켜고 지형을 누르면 그 위치를 사용합니다. 선택 모드에서 다시 버튼을 누르면 취소하고, 평소 왼쪽 드래그 밀기와 구분합니다. 설정은 기기 옵션에 저장합니다.

통합 모델 실행 중 목표 변경은 현재 몸·속도·관찰시간을 초기화하지 않습니다. 빠른 정지는 로봇 화면 오른쪽 위에 두며 현재 위치에 머물라는 목표만 전합니다. 최근 모델 관찰 중 정지를 누르면 몸을 재생성하지 않고 통합 모델 가중치로 전환합니다. 물리 정지나 기본 운동을 강제하지 않습니다. 제자리·목표 위치 도착에는 오차·속도 보상, 뒤로 이동에는 방향을 반영한 진행 보상, 낮은 자세에는 골반 높이 0.62m 목표 보상을 사용합니다. 근처 목표의 속도는 오차에 따라 줄어듭니다. 도움말은 동일한 상수를 사용해 이 기준을 설명합니다.

12개 후보 묶음마다 기본 운동 / 후진-정지·위치 도착·방향 전환 / 낮은 자세를 순환하고, 여섯 묶음마다 사용자가 학습 시작 전에 선택한 목표를 경험합니다. 목표 전환은 몸을 초기화하지 않고 4초 시점에 이루어집니다. 관절 동작은 계속 동일한 신경망이 결정합니다. CEM 채택 점수는 기존 다섯 과제의 정규화 보상 합에 고정 명령 시험(후진 후 정지·위치 도착·낮은 이동·왕복)의 정규화 평균을 더합니다. 운동 능력별 기존 네 조건 검증은 그대로 유지합니다. 미학습 목표 수행을 보장하지 않습니다.

### 화면·캐릭터·지형

상세 옵션에 캐릭터, 지형, 관찰시간(1~3600초·기본 30초), 관찰 갱신 간격, 자동 밀기 체크·세기 범위, 모든 학습 데이터 초기화가 있습니다. 관찰시간은 학습·검증 길이를 바꾸지 않습니다. 좁은 외부 화면에서는 과제·횟수와 실행 버튼을 하단에 고정하며 로봇 장면은 390×760에서 380px입니다. 내부 가로 화면은 좌우 배치입니다. 실제 Fold 하드웨어의 FPS는 별도 측정이 필요합니다.

캐릭터는 탐험가·깡통 로봇·스타워즈형·등산객·김도윤·임선아 6종이며 물리와 학습 정책은 동일합니다. 등산객은 굵은 팔다리, 측면 옷과 얇은 배낭을 표현합니다. 신발은 발과 발가락을 한 외곽선으로 연결하고 허리는 몸통·골반 단면을 잇는 면으로 틈을 메웁니다. 김도윤·임선아는 상C 작가의 [공식 작품](https://comic.naver.com/webtoon/list?titleId=836848)을 참고해 직접 그린 간단한 팬 스킨입니다. 참고 이미지를 배포하지 않습니다.

지형은 초원 → 사막 → 돌길 → 언덕 → 계단 → 공사장 → 빙판 → 동굴 탐험 순서입니다. 초원은 평지, 사막은 모래 언덕(마찰 0.65), 돌길은 낮은 둥근 돌·오르내림·젖은 바닥 마찰 0.25의 물웅덩이, 언덕은 최대 약 48도 곡면, 계단은 17cm 단과 휴식 평지, 공사장은 낮은 상자·파렛트·파이프·안전대입니다. 빙판은 평지·마찰 0이며, 동굴은 바닥 높낮이 5배와 최소 3.3m 천장 여유를 유지하고 별도 장애물은 없습니다. 표시 순서와 생성 시드를 분리합니다. 배경 제작은 `assets/README.md`를 참고하세요.

### 저장·이전 모델 보관·초기화

직접 제어 모델은 `mydesk.robot.v4`에 저장하며 버전 4·정책 종류 `direct-torque-goal-mlp-v2`·784개 가중치를 검증합니다. 내보내기는 `mydesk-robot-v4`이며 v3와 v4 파일을 불러올 수 있습니다. 직접 제어 v3의 44열 입력 행렬에 새 목표 입력 세 열을 0으로 추가해 기존 정책 출력·학습 횟수·분포를 유지하고, 기존 v3 저장 키는 원본 그대로 보관합니다. v4가 있으면 우선 사용합니다. v2는 기본 동작의 보정값이라 재사용하지 않습니다. v1/v2도 지우지 않고 v2는 도움말의 ‘이전 학습 기록 저장’으로 내려받을 수 있습니다. PC와 모바일은 각각 독립된 브라우저 저장소를 사용하며 로그인·서버 동기화는 없습니다.

전체 초기화는 브라우저 확인 창에서 취소할 수 있습니다. 확인하면 학습 작업자를 종료하고 `mydesk.robot.*`의 모델·횟수·그래프·백업·이전 버전 기록을 지운 뒤 0회 모델을 만듭니다. 캐릭터·상세 옵션과 다른 게임 데이터는 유지합니다. 초기화에는 이전 v2 보관본도 포함됩니다.

### 학습 속도 검증

`scripts/benchmark-robot.mjs`를 변경 전후 체크아웃에서 차례로 실행해 비교합니다. 2026-11-07 동일 실행 환경·초원·시드 42·자동 밀기 1~6 N·s·36회에서 학습 구간은 25.83초 → 13.00초(1.99배), 초기 검증 포함 전체는 29.36초 → 16.15초(45% 감소)였습니다. 36개 실제 시도 보상·최종 가중치·운동별 검증 보상·명령 보상은 정확히 일치했습니다. 기기·지형·학습된 모델에 따라 시간과 개선 폭은 달라집니다. 물리 하위 스텝·관절 제약·보상·요청 횟수는 줄이지 않습니다.

`node --test tests/robot-performance.test.mjs`는 지표 보고 생략·실제 시도 녹화의 물리 결과 동일성, 조기 기각/전체 검증의 채택 결과 동일성, 채택 가능 후보 전체 검증, 미평가 후보 그래프 공백, 동일 스레드 재사용·탐색 분포 유지·취소·지형 변경을 검증합니다. `node scripts/verify-robot-performance.cjs`는 브라우저에서 학습 중 자동 관찰의 메인 스레드 물리 호출 0회, 통합 실행·직접 밀기 실시간 전환, 운동 과제 전환과 두 차례 학습에 작업자 1개 유지, 추가 100회 정확한 학습·가중치/분포 저장을 검증합니다.

### 후보·검증 물리 병렬 계산

`robot-rollouts.mjs`와 `robot-rollout-worker.mjs`는 기존 학습 작업자 옆에 물리 계산용 작업자 하나만 추가합니다. `navigator.hardwareConcurrency >= 4`일 때 자동으로 사용하며, 2.5초 내 준비되지 않거나 중첩 작업자가 차단·실패하면 같은 시도를 순차 계산하여 복구합니다. 작업자 오류의 전파를 막고 결과를 누락하지 않습니다. 새로운 서버나 로그인은 없습니다.

CEM 가중치 추출·난수 소비·시드·카운터·모델 채택은 기존 학습 작업자 하나가 담당합니다. 두 후보를 미리 준비할 때 전체 시도 인덱스를 지정하고, 12개 후보 묶음 경계를 넘지 않습니다. 완료 순서와 무관하게 원래 순서로 결과를 반영하며, 요청 횟수 끝의 홀수 시도는 하나만 계산합니다. 중지 시 아직 반영하지 않은 추가 결과는 버리고 카운터를 늘리지 않습니다. 중단된 검증 묶음은 다음 학습에서 새 후보 생성 전에 마칩니다. 운동별 네 검증 조건과 네 명령 시험도 두 개씩 병렬 계산하되 합산 순서는 유지합니다.

관절 힘 계산의 반복 배열 생성과 관절 몸체 조회, 이미 정규화한 목표의 반복 정규화를 줄였습니다. 물리 스텝·토크·질량·관절 제약·보상은 변경하지 않았으며 모델 저장 형식은 v4 그대로입니다.

2026-11-07 동일 Chromium 환경에서 직전 v20 순차 계산과 v21 두 계산 경로를 강제 선택해 비교했습니다. 초원·시드 42·36회·자동 밀기 1~6 N·s에서 학습 12.79초 → 8.43초(추가 34.1% 감소, 1.52배), 초기 준비 포함 15.61초 → 11.24초였습니다. 모든 실제 시도 보상, 최종 가중치, mean/spread, 다섯 능력 검증 보상, 명령 보상, 학습 횟수가 정확히 일치했고 양쪽 모두 같은 후보를 1회 채택했습니다. 보고 코어 수는 3개인 테스트 환경이므로 병렬 경로는 벤치마크에서 명시적으로 켰습니다. 실제 자동 선택과 개선 폭은 기기 코어·브라우저·지형에 따라 다릅니다.

`node scripts/benchmark-robot-worker.cjs <base-url> <true|false> 36 <output.json>`으로 브라우저 작업자 경로를 비교합니다. `tests/robot-parallel.test.mjs`는 실제 별도 물리 스레드의 순차 결과 동일성, CEM 분포·카운터·가중치 보존, 전체 검증 일치와 실패 복구를 확인합니다. `scripts/verify-robot-parallel.cjs`는 브라우저에서 두 물리 계산 경로, 중지 후 늦은 결과 미반영, 운동 전환·재학습 100회·저장, 관찰 전환과 중첩 작업자 사용 차단 시 순차 복귀를 검증합니다.
