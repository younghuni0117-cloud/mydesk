# My Desk

정보와 자료, 배움의 기록을 모으는 개인 홈페이지입니다. 왼쪽 메뉴에서 홈, 정보·자료, 미로 탐험, 카트폴, 2D 로봇을 선택합니다. 각 콘텐츠는 독립된 HTML 페이지이며, 홈에서는 게임이 실행되지 않습니다. 모바일에서는 메뉴 버튼으로 사이드바를 여닫을 수 있습니다.

**홈페이지:** https://younghuni0117-cloud.github.io/mydesk/

## GitHub에서 수정하기

이 저장소의 `main` 브랜치에서 파일을 열고 연필(Edit) 버튼으로 수정한 뒤 Commit changes를 누르세요. GitHub Pages가 `main` 브랜치의 루트(`/`)에서 자동으로 다시 배포합니다. 진행 상황은 저장소 Actions 탭에서 확인할 수 있습니다.

자료를 추가하려면 `resources.html`에 내용을 넣고 필요에 따라 `index.html`에서 링크하세요. 새 페이지를 추가할 때 왼쪽 메뉴도 바꾸려면 각 HTML 파일의 `sidebar` 내 링크를 함께 수정합니다. 기존 공유 주소의 `#experiments`, `#cartpole`, `#how`는 새 게임 페이지로 연결됩니다.

## 로컬 실행

설치·빌드 없이 정적 서버로 실행합니다. 카트폴은 ES 모듈을 사용하므로 파일을 직접 열기보다 아래 명령을 사용하세요.

```sh
python3 -m http.server 8000
```

http://localhost:8000 에 접속합니다. Google Fonts를 불러올 수 없으면 기본 글꼴을 사용합니다.

## 강화학습 체험

미로는 탐험 비율과 속도를 조절하며 AI를 학습하거나 직접 이동할 수 있습니다. 학습 내용은 페이지를 벗어나면 초기화됩니다.

카트폴은 방향키와 터치로 직접 플레이하거나, 선택한 난이도의 AI를 학습한 뒤 보존 모델로 실행할 수 있습니다. 학습 시도 횟수(1~10,000회)를 직접 입력하며, 게임 시작부터 실패 또는 20초 성공까지가 1회입니다. 입력한 횟수를 정확히 수행하고, 실행은 자동으로 시작하지 않습니다. **학습 모델 실행**을 누르면 해당 난이도에서 가장 높은 고정 평가 평균 누적 보상을 얻은 모델의 가중치를 복사해 사용합니다. 실행 중 가중치는 바뀌지 않습니다.

### 난이도

| 난이도 | 물리·종료 조건 |
| --- | --- |
| 쉬움 | 긴 1단 막대, ±20° 허용 |
| 기본 | 기존 1단 막대, ±12° 허용 |
| 어려움 | 짧은 막대·높은 중력, ±10° 허용 |
| 2단 관절 | 두 막대를 직렬로 연결, 각 막대 ±20° 허용 |

모든 난이도에서 카트가 ±2.4m를 벗어나면 종료합니다. 1,000스텝(20초)을 버티면 성공입니다. 실패한 시점에 시간과 점수를 확정한 뒤, 제어 입력 없이 막대가 바닥에 닿아 튕기고 가라앉는 모션을 보여줍니다. 이 종료 모션은 학습 시도·생존 시간·보상에 추가되지 않습니다. 모션을 일시정지하거나 이어 볼 수 있습니다. 2단 관절은 두 균일 막대의 연성 질량 행렬을 풀고 두 번의 중점 적분으로 움직임을 계산합니다. 위·아래 막대의 각도와 각속도는 독립 상태입니다.

### 학습·그래프·저장

CEM(Cross-Entropy Method)으로 1단은 4개 가중치, 2단은 6개 가중치를 학습합니다. 1단은 묶음별 25개 후보·상위 6개, 2단은 49개 후보·상위 8개로 분포를 갱신합니다. 각 후보는 동일한 3개 학습 시작 조건을 시도합니다. 이후 각 묶음 후보를 **난이도별 고정된 8개 시작 조건**으로 평가합니다. 학습은 게임 시도 3회마다 브라우저에 제어를 넘겨 중지·난이도 전환이 가능하며, 완료한 시도는 즉시 횟수에 포함됩니다. 요청 횟수 도달 또는 중지 시 현재까지의 후보를 별도로 평가해 최고 모델을 보존합니다. 미완료 후보·평가 순서·부분 점수를 저장해 다음 요청에서 정확히 이어갑니다.

오른쪽 그래프의 회색 점선은 평가 시점별 후보의 평균 누적 보상, 파란 실선은 보존된 최고 모델의 평균 누적 보상입니다. 20초 성공률도 이 8회 평가 기준이며, 매 실행의 무작위 시작 조건에서 똑같은 결과를 보장하지 않습니다. 가로축은 누적 학습 시도 횟수입니다. 성능 확인을 위한 별도 8회 평가는 입력한 학습 시도 수에 포함하지 않습니다. 그래프에는 최근 120개 평가 기록을 표시합니다. 미리 훈련된 가중치나 정답 제어기는 사용하지 않습니다.

난이도별로 모델·학습 분포·진행 중인 후보 평가·그래프·내 최고 기록을 `mydesk.cartpole.v3.<difficulty>` localStorage에 나누어 저장합니다. 기존 v1/v2 모델 가중치·누적 시도·내 최고 기록은 불러와 유지하고, 새 보상 규칙으로 다시 평가합니다. 과거 시간 그래프를 점수로 변환하지 않으며, 새 보상 그래프는 이관 시점의 누적 시도에서 시작합니다. 점수 단위가 다른 미완료 v2 후보 평가는 이관하지 않고, 원본 저장 키는 보존합니다. 초기화 버튼은 현재 난이도의 AI 학습만 지우고, 내 최고 기록과 다른 난이도의 모델은 유지합니다.

### 상벌점 규칙

- 유효한 스텝(0.02초)마다 기본 +1점
- 자세 감점: −0.2 × 각 막대의 `(각도/허용 각도)²` 평균
- 위치 감점: −0.05 × `(카트 위치/2.4)²`
- 제어 감점: −0.01 × `입력 힘²`
- 실패 순간 −100점, 20초 성공 시 +100점

그래프·후보 순위·보존 모델 선택에 같은 실제 누적 보상을 사용합니다. 보상 범위는 −100~+1,100점이며 0점 기준선을 표시합니다. 실패 후 충돌 모션은 보상에 영향을 주지 않습니다.

바닥 충돌은 질량 행렬을 통한 수직 충격량, 반발계수 0.38, 접선 마찰과 위치 보정을 적용합니다. 마찰이 수직 반발을 지우지 않도록 제약 공간에 투영합니다. 1단·2단 모두 전체 막대가 카메라에 들어오도록 시야를 조절합니다.

검증: `node --test tests/cartpole.test.mjs tests/cartpole-motion.test.mjs`

기존 Sites 사이트는 별도 배포이며, 이 저장소의 변경은 GitHub Pages 주소에 반영됩니다.

## 모바일·폴더블 게임 화면

두 게임은 기기 이름 대신 실제 가용 화면 크기로 배치합니다. 좁은 화면(너비 600px 미만)은 게임판 위·조작부 아래, 넓은 화면은 게임판과 조작부를 나란히 배치합니다. 회전한 외부 화면은 너비 540px 이상·높이 540px 미만일 때 가로 배치를 사용합니다. 게임 페이지에서는 내부 화면에서도 왼쪽 메뉴를 접어 게임 공간을 확보합니다.

화면 높이는 `visualViewport`와 동적 뷰포트에 맞추며, 접기·펼치기·회전·브라우저 주소창 크기 변화에 따라 다시 계산합니다. 도움말은 별도 대화상자에서 읽고, 지원 브라우저에서는 전체 화면 버튼을 사용할 수 있습니다. 게임 진행 화면에는 모드, 기록, 설정, 핵심 조작을 유지합니다. 도움말을 열면 진행·학습을 일시정지합니다.

가용 높이가 지나치게 작거나 브라우저를 확대하면 조작을 잘라내지 않도록 일반 스크롤 배치로 돌아갑니다. 실기기·브라우저 화면 검증은 별도로 필요합니다.

## 로봇 강화학습

`robot.html`에서 하나의 로봇으로 균형·일어서기·걷기·달리기·장애물 통과를 학습합니다. 17개 강체와 16개 모터 관절을 Planck 1.5.1로 계산합니다. 보조 지지력·복원 토크는 제거했습니다. 양팔도 다리처럼 같은 측면 축에 투영하고, 헬멧·재킷·장갑·부츠의 만화풍 캐릭터 스킨을 실제 관절에 맞춰 표시합니다. `robot-skin.mjs`는 부위별 그림을 캐시합니다. 변경된 어깨 배치에서 기존 파라미터를 그대로 불러와 성능을 다시 검증하며 학습 횟수는 유지합니다. 부품의 자기 충돌은 제외하고 바닥·장애물 접촉을 계산합니다.

### 하나의 공통 정책

자세·회복·보행 기본 제어기의 32개 항에 16개 관절별 독립 반응 6개씩을 더한 총 128개 파라미터를 CEM으로 탐색합니다. 각 관절은 개별 시간 위상, 몸통 각도, 관절 속도, 해당 발 접촉, 앞 지형 높이에 서로 다른 가중치를 가지므로 좌우의 같은 동작을 강제하지 않습니다. 자유로운 신경망을 처음부터 학습하는 방식은 아니며 성공을 보장하지 않습니다. 오른쪽의 운동 과제 하나로 학습과 실행 상황을 정합니다. 왼쪽 하단 진행 게이지는 이번 요청의 완료 시도 수와 비율을 표시하며, 중지하면 그 비율을 유지합니다. 선택 즉시 관찰 화면도 바뀌며 과제를 바꿔도 가중치를 교체하지 않습니다. 접었다 펼 수 있는 상세 옵션에서 탐험가·깡통 로봇·스타워즈풍 외형, 지형·난이도, 로봇 수를 선택합니다. 외형은 물리 조건·가중치를 바꾸지 않고 `mydesk.robot.skin` 키에 따로 저장합니다. 후보 12개 중 상위 4개로 분포를 갱신합니다. 후보 정책은 다섯 과제 전체에서 재검증하며 종합 보상 지수가 높아지고, 이전 통과 조건을 모두 유지하고, 각 과제 평균 보상 하락이 max(1점, 기존 절댓값의 2%) 이내인 경우만 채택합니다. 이는 정해진 검증 사례의 퇴행 방지이며 모든 실제 상황의 보장은 아닙니다.

시도 횟수 선택은 100·200·500·1,000·2,000·5,000·10,000·100,000회입니다. 1회는 과제별 8~12초 가상 시간의 실제 시뮬레이션입니다. 검증과 관찰 재생은 학습 횟수에 포함하지 않습니다. 과제별 시도의 합이 전체 횟수입니다. 표의 다섯 보상·통과율은 모두 현재 공통 모델에 대한 결과입니다. 전체 조건 누적 횟수와 검증 조건 설명은 주 화면에서 제거했습니다. 그래프는 `20 × Σ tanh(각 과제 평균 보상 / 40)`의 −100~100 지수이며 표는 정규화하지 않은 실제 보상입니다. 작은 변화도 보이도록 표시 범위를 자동 조절하고 높이는 기존의 약 절반으로 줄였습니다. 그래프 왼쪽 세로축에 최댓값·중간값·최솟값을 표시합니다.

### 외력에 대한 균형 훈련

훈련에서 앞뒤·기울어진 방향, 몸통·어깨·골반, 충격·지속 힘을 변화시킵니다. 처음 100회는 최대 2 N·s, 100회부터 4, 500회부터 6까지 확장합니다. 실제 밀림 이후 1.5초 동안 서 있으면 추가 보상을 주고 쓰러진 상태에는 감점합니다. 기울기·충돌·넘어짐·에너지를 감점하고, 서 있기·목표 속도·진행·회복·장애물 통과를 보상합니다.

각 과제는 무외력, 앞뒤 2 N·s, 어깨·골반 4 N·s, 앞뒤 6 N·s의 고정 네 조건에서 검증합니다. 균형은 서 있는 비율 >95%, 넘어짐 0회, 최종 골반 높이 >0.75m, 이동 절댓값 <1m를 모두 요구합니다. 일어서기는 회복 1회 이상과 최종 높이 >0.75m, 걷기는 전진 >1.5m·서 있는 비율 >60%, 달리기는 전진 >4m·서 있는 비율 >50%, 장애물은 통과 1개 이상·서 있는 비율 >50%입니다. 100%도 임의의 외력에 대한 안전 보장이 아닙니다.

### 관찰·조작·화면

핵심 버튼은 학습 시작·모델 실행·중간 관찰 순서입니다. 별도 밀기 메뉴와 절전 선택은 제거했습니다. 중간 관찰은 10·20·50·100회 간격으로 공통 보존 모델 또는 최근 후보를 실제로 실행한 물리 궤적입니다. 모델 실행은 현재 가중치를 복사해 시험하며 직접 밀기는 학습에 추가되지 않습니다. 관절 각도 표는 제거했습니다. 휠·두 손가락·버튼으로 50~250% 확대하고 마우스 오른쪽 드래그로 시점을 옮기고 왼쪽 드래그로 선택한 로봇을 밉니다. 드래그 방향·길이를 충격 방향·크기로 바꿉니다. 여러 로봇 중 드래그 시작점에 가장 가까운 로봇에만 적용합니다. 맞춤은 로봇 추적을 복구합니다. 한 손가락 터치는 밀기, 두 손가락은 화면 이동·확대에 사용합니다. 좁은 폴드 외부 화면은 위아래, 넓은 내부 화면은 좌우로 배치합니다. 로봇 페이지는 화면 높이에 강제로 맞추지 않고 스크롤을 허용하며 외부 화면 장면 높이는 가용 공간에 따라 200~390px로 조절하고, 짧은 화면에서도 게이지가 하단 버튼 위에 보이도록 여백을 줄입니다. 확대·축소 도구는 장면 위에 배치했습니다. 페이지를 스크롤하려면 로봇 캔버스 바깥을 드래그합니다. 외부 화면에서는 학습 시작·모델 실행·중간 관찰 버튼을 화면 하단에 고정해 스크롤 위치와 관계없이 사용합니다. 운동 과제·시도 횟수 라벨은 줄바꿈하지 않습니다. 내부 가로 화면(너비 600px 이상, 가용 높이 480px 이상, 너비 > 높이)은 장면과 전체 도구가 한 페이지에 맞도록 배치합니다. 브라우저를 확대하면 스크롤 배치로 돌아갑니다. 그래프는 가용 높이에 맞춰 늘어나며 숫자 축을 유지합니다.

학습은 현재 기기의 CPU에서 이루어집니다. 절전 기능과 65ms 대기는 제거했습니다. 시도 사이에는 UI와 중지 신호 처리를 위해 제어를 넘깁니다. 재생 샘플을 30Hz로 기록하고 실제 타임스탬프로 보간하며, 실시간 실행도 고정 물리 틱 사이를 보간합니다. 모바일 렌더링 해상도를 최대 DPR 1.5로 제한하고 캐릭터 부위 스킨을 캐시하며, 시도마다 표·그래프 전체를 다시 그리거나 모델 전체를 저장하지 않도록 줄였습니다. 실제 기기 FPS는 별도 확인이 필요합니다. 창이 숨겨지면 중지를 요청하고 완료한 시도와 보존 모델을 저장합니다. 시도나 과제 검증 계산 중에는 해당 계산이 끝나야 중지할 수 있습니다.

### 지형과 동시 학습

`robot-terrain.mjs`는 초원·언덕·공사장·계단·한쪽 발 돌길·빙판을 생성합니다. 쉬움·보통·어려움에 따라 경사·계단 높이·돌 크기가 달라집니다. 지형은 실제 정적 충돌체이며 화면 배경만 바꾸는 기능이 아닙니다. 왼발·오른발 전용 돌은 서로 다른 충돌 마스크를 사용하며 주황색·파란색으로 표시합니다. 발별로 앞 장애물을 조회하고 지형 높이 대비 골반 높이를 평가합니다. 지형 변경 시 현재 공통 가중치를 유지해 해당 지형에서 다섯 능력을 재검증하고 새 보상 그래프를 시작합니다. 과거 누적 횟수는 유지합니다.

로봇 수는 기본 1개, 최대 10개입니다. `robot-team.mjs`는 로봇별 Web Worker를 생성해 실제로 동시에 탐색하며, 서로 독립된 물리 환경을 간격을 두어 표시합니다. 로봇끼리 충돌하지 않습니다. 전체 요청 시도 수를 각 로봇에 분배하고 완료한 실제 시도만 합산합니다. 예를 들어 10개·100회는 각 10회씩 총 100회입니다. 후보는 같은 지형의 다섯 운동 능력 검증을 거쳐, 기존 능력을 보존하고 종합 점수가 높을 때 공통 모델에 채택합니다. 단순히 가중치를 평균내지 않습니다. 모델 실행은 모든 로봇이 현재의 공통 보존 정책을 사용하며 학습 관찰은 각 탐색기의 장면입니다. 화면 지표는 1번 로봇 기준으로 표시합니다.

로봇 수 변경 시 시야를 맞추고 4~250%까지 확대·축소할 수 있습니다. 여러 로봇의 실제 병렬 속도는 해당 기기의 CPU 코어 수에 따라 달라집니다.

### 기기별 저장·이관

`mydesk.robot.v2`에 공통 모델·분포·과제별 횟수·검증·보상 기록을 저장합니다. v2 파일 내보내기·불러오기를 지원합니다. 기존 v1 원본은 지우지 않으며, 가장 높은 기존 보상의 후보 최대 3개를 새 무보조 조건에서 다시 평가해 초기 공통 정책을 선택하고 과제별 실제 시도 수를 이관합니다. 기존 보조 상태의 성공률·보상 그래프는 이어 붙이지 않습니다. 저장된 모델은 불러올 때도 실제 물리로 다시 검증합니다.

로봇 학습은 각 기기의 브라우저에만 자동 저장합니다. PC·모바일은 각각 독립된 모델과 학습 횟수를 유지하며 로그인과 자동 동기화는 사용하지 않습니다. 기존 `mydesk.robot.v2` 저장 키를 유지하고, 32개 정책은 기존 항을 그대로 보존하면서 추가 항을 0으로 확장합니다. 따라서 이전 브라우저 학습 결과는 유지됩니다. 도움말에서 모델 파일을 내보내거나 직접 불러오는 기능은 유지합니다. 브라우저 저장 데이터를 지우면 로컬 학습 결과도 삭제됩니다.

검증: `node --test tests/robot.test.mjs tests/robot-terrain.test.mjs tests/robot-ui.test.mjs tests/robot-layout.test.mjs tests/robot-view.test.mjs`. 물리 단위 검증과 실제 작업 스레드 UI 검증에 더해 로컬 Chromium에서 상세 옵션·3개 및 10개 로봇·학습·모델 실행·마우스 조작·로컬 저장을 확인합니다. 실제 Fold 기기의 FPS·화면 검증은 별도입니다.

브라우저 통합 검증은 Playwright와 Chromium이 있는 환경에서 로컬 서버를 실행한 후 `node scripts/verify-robot-browser.cjs`로 재현할 수 있습니다. `CHROMIUM_PATH`와 `ROBOT_BASE_URL`로 실행 파일·서버 주소를 지정합니다. 10개의 실제 Web Worker, 총 100회 완료·저장·진행률 및 마우스 좌/우·휠 조작을 확인합니다.
