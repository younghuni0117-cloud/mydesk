NVIDIA PhysicsNeMo는 물리 머신러닝(physics ML), 과학 머신러닝(SciML), 과학·공학을 위한 AI에 사용하는 오픈소스 PyTorch 프레임워크입니다. 재사용 가능한 라이브러리 구성요소와 처음부터 끝까지 이어지는 학습 예제를 제공합니다.

pip install "nvidia-physicsnemo[cu13]"

위 명령은 CUDA 13 백엔드를 선택합니다. CUDA 12, 기본 설치, 선택 기능, 소스 코드 설치는 설치 옵션을 참고하세요.

PhysicsNeMo를 사용하는 이유

  • PyTorch 기반이며 조합하기 쉽습니다. 기존 PyTorch 작업 흐름을 바꾸지 않고도 완성된 아키텍처, 개별 레이어, 수치 연산자 또는 데이터 변환을 사용할 수 있습니다.
  • 과학 데이터의 표현을 고려합니다. 규칙 격자, 메시, 점군, 그래프, 중첩된 물리장을 원래 구조를 유지하면서 다룹니다.
  • 샘플 자체의 규모를 확장합니다. ShardTensor 영역 병렬화를 사용하면 고해상도 샘플 하나를 여러 GPU로 나누어 처리할 수 있습니다. PyTorch의 DistributedDataParallel(DDP)이나 Fully Sharded Data Parallel 2(FSDP2)와 함께 사용할 수 있습니다.

  • 공학 설계·전산유체역학(CFD): 통합 외부 공력 예제로 표면·체적 모델을 학습하고 비교하거나, 데이터센터 기류 예제로 예측을 가속합니다.
  • 날씨·기후·물: 기상 예제로 전 지구 예측을 구성하거나 홍수를 예측합니다.
  • 구조·제조: 변형하는 구조물의 거동을 모사합니다.
  • 지구물리·지하 시스템: 저류층 대리모델을 구성합니다.
  • 의료: 뇌 이상 탐지를 수행합니다.
  • 생성형·역문제 물리: 확산 도구 모음과 위상 생성 예제를 조합합니다.
  • 시뮬레이션·데이터 반복 과정: 능동 학습으로 새로 수행할 시뮬레이션을 선택합니다.

모델 계열 선택하기

화살표는 계층 간 import 규칙에서 허용하는 의존성 방향을 따릅니다. 그림은 단순화한 것이며, 각 계층의 공개 기능은 아래 링크에서 확인할 수 있습니다.

  • 응용 프로그램과 작업 흐름: 실행 가능한 예제, 중단 후 다시 시작할 수 있는 능동 학습 반복 과정, 확산 모델의 스케줄러·샘플러·가이던스·멀티 디퓨전.
  • 물리 AI 구성요소: 최적화된 모델, 리더·변환·GPU 전처리·다중 데이터셋 샘플링을 위한 데이터 파이프, 평가 지표, ShardTensor 영역 병렬화, 최적화.
  • 재사용 가능한 기반 요소: GPU 토폴로지·공간 질의·재메시·미분 가능한 변형을 지원하는 Mesh와 DomainMesh, 미분·보간·기하·샘플링·렌더링을 위한 신경망 레이어와 수치 함수, 체크포인트·로그·프로파일링용 유틸리티, 분산 FFT 등을 포함한 분산 처리 기본 요소, 모델 수명주기 코어.

실험 모듈에서는 GLOBE, AeroJEPA 같은 모델과 함께 불확실성 정량화, 가드레일, LoRA를 이용한 파라미터 효율적 미세 조정, 그 밖의 연구 도구를 개발합니다.

API 안정성: physicsnemo.experimental 아래의 API는 개발·검증 단계이므로 릴리스 사이에 바뀔 수 있습니다. 안정 모듈에는 프로젝트의 시맨틱 버전 관리 정책이 적용됩니다. API 변경·제거 사항은 변경 이력을 확인하세요.

코딩 에이전트와 함께 사용하기

저장소에는 NVIDIA가 작성한 스킬 두 가지가 포함되어 있습니다. Codex, Claude Code 및 호환되는 코딩 에이전트에서 사용할 수 있습니다.

  • PhysicsNeMo Discover: SciML 작업에 맞는 모델, 데이터 파이프, 예제와 문서를 찾습니다. 평가 결과.

설치 옵션

현재 지원하는 Python 버전, 선택 의존성 그룹, 정확한 의존성 제약은 pyproject.toml을 확인하세요. README 처음에 나온 명령은 CUDA 13 백엔드를 선택합니다. CUDA 12 백엔드를 사용하려면 다음과 같이 설치합니다.

pip install "nvidia-physicsnemo[cu12]" \
  --extra-index-url https://download.pytorch.org/whl/cu129

pip는 pyproject.toml의 패키지 인덱스 설정을 읽지 않으므로 CUDA 12.9용 PyTorch 인덱스를 명시해야 합니다. CUDA 12 백엔드는 Linux 전용이며, CUDA 12.9 휠을 제공하는 가장 최신 릴리스인 PyTorch 2.13을 사용합니다.

PyPI의 기본 PyTorch 배포판을 사용하고 CUDA 전용 RAPIDS 패키지는 설치하지 않는 기본 설치는 다음과 같습니다.

pip install nvidia-physicsnemo

선택 기능은 어느 백엔드와도 조합할 수 있습니다. 예를 들면 다음과 같습니다.

pip install "nvidia-physicsnemo[cu13,gnns]"

uv로 소스 코드를 받아 개발하려면 다음과 같이 진행합니다.

git clone https://github.com/NVIDIA/physicsnemo.git
cd physicsnemo
uv sync --extra cu13

역자 주 — 버전 기준: 위 설치 명령과 조건은 확인한 커밋의 원문을 번역한 것입니다. 같은 커밋의 pyproject.toml은 Python >=3.11,<3.15, CUDA 12 그룹의 PyTorch >=2.13.0,<2.14를 명시합니다. 설치 명령을 이 블로그에서 실행하거나 GPU 호환성을 시험한 것은 아닙니다. 실제 설치 시 사용할 릴리스의 요구사항을 확인하세요.

학습 자료

Hugging Face의 PhysicsNeMo 노트북, AI for Science 부트캠프, NVIDIA Deep Learning Institute 자기 주도 학습 과정을 통해 배울 수 있습니다.

사전 학습 모델과 데이터셋은 NGC 카탈로그에서 확인할 수 있습니다.

커뮤니티와 기여

라이브러리, 예제와 문서에 대한 기여를 환영합니다.

  • GitHub Discussions에서 질문하고 작업을 공유하세요.
  • GitHub Issues로 버그를 제보하거나 기능을 제안하세요.
  • help wanted 라벨이 붙은 이슈를 찾아보세요.
  • 풀 리퀘스트를 열기 전에 기여 안내를 읽고, 이슈나 토론에서 유지관리자와 제안 작업을 조율하세요. 모든 풀 리퀘스트는 열려 있는 이슈와 연결되어야 합니다. 큰 변경은 구현을 시작하기 전에 유지관리자의 피드백을 기다리세요.
  • 행동 강령을 따르고, 취약점은 보안 정책에 따라 비공개로 신고하세요.

릴리스 이력과 업그레이드 안내는 변경 이력, GitHub 릴리스, v2 마이그레이션 가이드를 참고하세요.

인용

PhysicsNeMo가 연구에 도움이 되었다면 CITATION.cff의 메타데이터를 사용해 프로젝트를 인용하세요.

영역 병렬화를 사용하는 연구는 ShardTensor: Domain Parallelism for Scientific Machine Learning도 인용해야 합니다. PhysicsNeMo-Mesh(physicsnemo.mesh)를 사용하는 연구는 PhysicsNeMo-Mesh: GPU-Native Meshes and Simulation Cases for Physics AI도 인용해야 합니다.
